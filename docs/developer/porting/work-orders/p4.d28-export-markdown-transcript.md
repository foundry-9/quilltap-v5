### 1. The renderer — `lib/export/markdown-transcript.ts` → NEW `crates/quilltap-core/src/services/markdown_transcript.rs`

that is P4.6BM's Scriptorium CONVERSATION_RENDER renderer (v4's
`lib/scriptorium/markdown-renderer.ts`), a different file.

Exports: `MarkdownTranscriptInput` (:64–76) `{ chat, events /* from
getMessages, createdAt-ascending */, characterNamesById, userName,
defaultTimestampConfig?, chatSettingsTimezone? }`;
`buildMarkdownTranscript(input) -> string` (:166–229) — **pure, no
wall-clock reads** (v4's header promises byte-identity and its own test
pins determinism); `transcriptFilename(chat)` (:232–235).

Constants:
- `HOST_LINK_KINDS = {'continuation-from','continuation-to','merge-from',
  'merge-to'}` (:38).
- `STAFF_DISPLAY_NAMES` (:41–53): lantern→'The Lantern', aurora→'Aurora',
  librarian→'The Librarian', concierge→'The Concierge', prospero→'Prospero',
  host→'The Host', commonplaceBook→'The Commonplace Book', ariel→'Ariel',
  **suparna→'Suparṇā' (non-ASCII — byte-transcribe, don't retype)**,
  pascal→'Pascal', carina→'Carina'. No shared v5 equivalent exists (the
  closest, `courier_transport.rs:36–50`'s `courier_system_sender_label`,
  lacks three entries and wraps in `[Staff: …]`) — transcribe fresh.
- `FALLBACK_CONFIG` (:56–62): `{mode:'NONE', format:'FRIENDLY',
  useFictionalTime:false, autoPrepend:true, intervalMinutes:15}`.

Inclusion filter `isTranscriptMessage` (:79–88), exact: SYSTEM/TOOL roles →
exclude; `systemSender` 'pascal'/'carina' → include (all kinds); 'host' →
only `systemKind ∈ HOST_LINK_KINDS`; any other Staff → only `systemKind ===
'announcement'`; otherwise include. Upstream (:186–188): `events.filter(e =>
e.type === 'message')` first.

Speaker resolution `resolveSpeakerName` (:95–135), precedence: (1)
`customAnnouncer` wins — character kind with characterId → map name else
'Off-scene character'; else `displayName || 'Announcement'`; (2) carina:
`carinaMeta.answererId === BRAHMA_CARINA_ANSWERER_ID`
(`'b4a4c0de-0000-4000-8000-000000000001'` — v5 has the same UUID at
`carina_query.rs:83`) → 'Brahma'; named answerer from map; else 'Carina';
(3) other systemSender → `STAFF_DISPLAY_NAMES[sender] ?? sender` (raw-key
fallback); (4) participantId → participant → character name (broken vaults
fall through); (5) role USER → userName; (6) fallback →
`primaryCharacterName ?? 'Assistant'`.

Swipe collapse `collapseSwipes` (:141–163): pass 1 per `swipeGroupId` keeps
highest `swipeIndex` (strict `>` — first-seen wins ties); pass 2 emits each
group ONCE at its first chronological position. (Deliberately NOT the
ST-export's order-sensitive algorithm in v5's `services/chat_export.rs`.)

Layout (:166–229): effective config = `chat.timestampConfig ??
defaultTimestampConfig ?? FALLBACK_CONFIG`; **promotion** — DATE_ONLY /
TIME_ONLY → spread-copy with `format:'FRIENDLY'` (:171–174; note
`resolveTimezone` is called on the ORIGINAL config, same timezone value);
`fallbackAnchor = new Date(chat.createdAt)` (:176); `primaryParticipant` =
first CHARACTER participant in stored order (:181); `# ${headingSafe(title
|| 'Untitled Chat')}`; scenario — `processTemplate(scenarioText, {char,
user})` trimmed, emitted under `## Scenario` when non-empty (v5:
`templates.rs:97 process_template`); per message: heading `##
${speaker}${whisper} — ${formatted}` (space-EMDASH-space, U+2014), whisper
suffix `' (whisper)'` when `targetParticipantIds` non-empty (:209–210),
timestamp via `calculateTimestampAt(new Date(msg.createdAt),
effectiveConfig, timezone, fallbackAnchor)`; body = `content.trim()`
(empty → heading only); `headingSafe` = `replace(/\s+/g,' ').trim()`
(title + speaker names, NOT timestamps); terminal normalization
`replace(/\n*$/,'\n')` — exactly one trailing newline.

`transcriptFilename`: `(title || 'chat').replace(/[<>:"|?*\x00-\x1f/\\]/g,
'_').trim() || 'chat'` + `'_transcript.md'` — non-ASCII survives, so the
RFC 5987 header arm is reachable (unlike the ST export).
