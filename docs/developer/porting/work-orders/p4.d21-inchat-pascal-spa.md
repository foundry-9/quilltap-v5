## Shared contract (binding — identical in all four sibling orders)

**§1 — `references` on a chat custom-tools listing.** Emitted by **P4.d19**,
consumed by **P4.d21**. Verbatim:

```jsonc
// GET /api/v1/chats/{id}/custom-tools → { tools: [ { ... } ] }
// Each listing gains ONE new key, positioned after `parameters`
// and before `defaultVisibility`:
"references": {
  "value":    false,        // boolean — some rendered string quotes {{value}}
  "roll":     false,        // boolean — {{roll}}
  "dice":     false,        // boolean — {{dice}}
  "llm":      false,        // boolean — {{llm}}
  "params":   [],           // string[] — DECLARED params quoted as {{params.x}}, sorted (en-US collation)
  "metadata": [],           // string[] — keys from when.metadata, BOTH gate clauses, and {{metadata.x}}, sorted
  "state":    []            // string[] — paths from $state refs and {{state.x}}, sorted
}
```

All seven keys are **always present** (never absent, never null). A tool that
quotes nothing yields four `false`s and three `[]`s — the consumer renders no
panel in that case (`isEmptyVocabulary`).

**§2 — `gate` on the Workbench surfaces.** Emitted by **P4.d19**, consumed by
**P4.d20**. Verbatim:

```jsonc
// (a) GET /api/v1/custom-tools (the library) — each entry gains ONE key,
//     positioned after `disabled` and before `defaultVisibility`:
"gate": "available" | "withheld" | null

// (b) POST /api/v1/custom-tools?action=preview — the response gains ONE
//     OPTIONAL key, present ONLY when the definition declares a gate:
"gate": { "available": true }                                  // available
"gate": { "available": false, "withheldBy": "availableWhen" }  // or "withheldWhen"
// `withheldBy` is ABSENT (not null) whenever `available` is true.
// The bench still deals: the run result is unchanged and always present.
```

**§3 — the `pascal-custom-tool-definition` corpus.** ONE source of truth:
`harness/oracle/cases/pascal-custom-tool-definition.ts`, owned by **P4.d19**,
which regenerates BOTH committed copies. **P4.d21 does not touch it.**

**§4 — the definition key names and order.** `availableWhen` and
`withheldWhen`, both optional, at most one per file, positioned after
`disabled` and before `revealOdds`, each shaped
`{ "metadata": { "<key>": { <one or more of gt|gte|lt|lte|eq|neq|contains|ncontains> } } }`
with **literal operands only**. P4.d21 consumes only the *effect* (gated tools
are simply absent from the roster it renders).
