## The drift, classified (surveyed 2026-08-18)

in both directions** — the tripwires will fire at the first regen, BY
DESIGN — plus a strip of genuinely new v4 surface (named import warnings)

**Bug 78 (avatar crash on pre-hair four-key `equippedOutfit` rows).** v4's
`getEquippedOutfit` read the column through a raw cast; the resolver
indexed `slots['hair']` → `undefined` → "rootIds is not iterable". v4 now
adds `normalizeEquippedSlots` (`lib/schemas/wardrobe.types.ts`) as the
single coercion point out of the column: schema-parse first, and on
failure a key-by-key salvage (each slot keeps its string elements,
non-arrays become `[]`). `getEquippedOutfit`
(`lib/database/repositories/chats.repository.ts`) maps every character's
entry through it — which also heals the two soft-degrading readers
(scene-state tracker, context manager) that were silently dropping
clothing from the model's view — and `wardrobe-create-handler` now reads
through the repository instead of by hand. `resolve-equipped.ts` keeps its
`?? []`. **v5 was never affected** — `Slots::from_value`
(`crates/quilltap-core/src/wardrobe.rs:573`) already defaults an absent
key to `[]` and salvages per-element — so the expected outcome here is
tripwire retirement plus semantic verification, not a port.

**Bug 79 (import swallowed destination read errors).** v4's `safeQuery`
4-arg fallback mode answered a thrown read with the fallback; the import's
reconcile consumed that as "no such row" and proceeded into a partial
apply. v4 now adds `lib/database/repositories/strict-failures.ts` (an
AsyncLocalStorage strict scope, 55 ln) and one `&& !strict` in
`safe-query.ts`; both import entry points AND `previewImport` are wrapped;
the trailing embedding-enqueue phase is wrapped back OUT
(`withRepositoryFallbacks`). New named warnings land on five arms that
previously only logged — `importTags`, `importRoleplayTemplates`, and all
three profile importers — and the preserveIds preflight abort now
populates `warnings` instead of returning `success: false` with an empty
array (which had also broken rehydrate's "unknown import error"). **v5
already refuses loudly at its 23 sites** (P4.48, the standing
fix-don't-match ruling) — but v5's skip sentences were invented while v4
had no fixed behavior to match. **v4 is now fixed, so the ruling's premise
is discharged: v5 re-converges to v4's new observable behavior,
byte-for-byte where the differential can see it.**
