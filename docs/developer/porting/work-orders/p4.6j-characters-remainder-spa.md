## Shared contract (BINDING — identical in `p4.6i`)

The eight `Request` variants (already in the Rust `api/types.rs` and to be
mirrored in `core-contract.ts`):

- `characterDelete {characterId, cascadeChats?, cascadeImages?}`
- `characterCascadePreview {characterId}`
- `characterChats {characterId, search?, limit?, offset?}`
- `characterExport {characterId, format?}` — `format:'json'` only until PNG
  lands; the SPA downloads the returned JSON client-side.
- `characterImport {payload}` — JSON body leg; PNG is the multipart web
  route (deferred).
- `characterPhotoList {characterId, limit?, offset?}`
- `characterPhotoSaveById {characterId, fileId?, linkId?}` — exactly one of
  `fileId`/`linkId`.
- `characterPhotoRemove {characterId, linkId}`

Response payload field lists (mock against these; lane A pins the bytes):

- **CharacterDelete** → `{success, deletedChats, deletedImages,
  deletedMemories}`.
- **CharacterCascadePreview** → `{characterId, characterName,
  exclusiveChats: [{id, title, messageCount, lastMessageAt}],
  exclusiveCharacterImageCount, exclusiveChatImageCount,
  totalExclusiveImageCount, memoryCount}`.
- **CharacterChats** → `{chats: [{id, title, createdAt, updatedAt,
  lastMessageAt, character: {id, name}, project: {id, name} | null,
  storyBackground: {id, filepath} | null, messages: [{id, role, content,
  createdAt}] (≤3, recent-first), tags: [{tag: {id, name}}],
  isDangerousChat, _count: {messages, memories},
  scriptoriumStatus: 'embedded'|'rendered'|'none'}], total}`.
- **CharacterPhotoList** → `{entries: CharacterGalleryEntry[], total,
  hasMore}` — `CharacterGalleryEntry` fields pinned by lane A in its first
  commit (at minimum `{linkId, filepath, caption, tags}`); code defensively
  and reconcile at unification.
- **CharacterPhotoSaveById** → the saved entry `{linkId, …}`.
- **CharacterPhotoRemove** → `{deleted, fileGC}`.
- **CharacterExport (json)** → the ST character-card object.
- **CharacterImport** → `{character: <created character>}`.

If any name or field must change, BOTH orders change and it is reported at
unification.
