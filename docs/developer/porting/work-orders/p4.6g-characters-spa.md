## Mandate

DETAIL/VIEW page (tabbed, per-field autosave), and the EDIT page
(form-with-explicit-save) — v4-faithful in structure, microcopy, and

(wardrobe dialog, AI wizards, optimizer) OUT per the deferral list.

### 2. The LIST page (v4 `app/aurora/AuroraView.tsx`, 711 lines)

- Data: `characterList` dispatch via TanStack Query.
- Cards (`qt-entity-card character-card`): avatar (resolved
  `defaultImage.filepath` with `?v={defaultImageId}` cache-bust; first-letter
  initial fallback), name, title, chat count, `ProviderModelBadge`-equivalent
  when `defaultConnectionProfileId` set, description preview (line-clamp-3,
  run through the ported `processTemplate` TS equivalent for
  `{{char}}`/`{{user}}` — a small pure TS port of the token substitution,
  NOT the full template processor).
- The three inline toggles (favorite star / Carina monitor / controlledBy
  user icon) with optimistic updates → `characterFavorite` /
  `characterToggleCarina` / `characterToggleControlledBy`.
- Card actions: **Chat** (link into the existing New-Chat path — if no
  chat-creation UI exists yet, link to `/salon` prefiltered or defer the
  button with the v4 microcopy grayed; decide at build time and note it),
  **Export** (JSON download via the dispatch or a direct GET), **Delete**
  (the delete dialog with the `cascadeChats`/`cascadeImages` checkboxes,
  wired to `characterDelete`; show the `characterCascadePreview` counts).
- Sort: NPCs last → favorites first → chat count desc → name A–Z
  (`AuroraView.tsx:125-140`, port verbatim). **v4 has NO search box or
  tag-filter on this page** — do not invent one this round.
- Toolbar: **Create Character** → `/characters/new`; **Import from
  SillyTavern** (file-upload dialog → `characterImport` for JSON; the PNG
  leg posts multipart to lane A's web route); **Summon From Lore** and
  **Reset Built-ins** render DISABLED with tooltips (Tier-3 server
  deferrals). Groups grid: OUT of scope (no groups contract yet) — omit
  the section entirely, note the deferral.
