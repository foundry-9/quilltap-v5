## Why (the escalation this discharges)

P4.31 tier-2 item 7 measured v4's overwrite import keeping folders an
archive no longer mentions: stale empty husks (the same orphan shape
P4.31 closed at the delete end), plus UNIQUE-constraint warnings and a
zero `documentStoreFolders` count on re-importing an IDENTICAL archive
(the survivors block the re-insert). The obvious fix was reverted by the
lane because the fixture's archives lack the six scaffold folders
`create_character` writes — but the ruling establishes that a REAL
exported vault always carries its full folder tree (the exporter dumps
every folder row: `~/source/quilltap-server/lib/export/
ndjson-writer.ts:513-524`), so the scaffold-loss arm is an archive shape
no real export produces, and round-trip fidelity wins. The name-matching
half fell out of the same investigation: `byName.get(mp.name
.toLowerCase())` means an archive overwrites whatever store happens to
WEAR the name today — renames silently redirect an overwrite onto an
unrelated store.
