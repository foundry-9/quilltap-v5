## Part 1 — courier transport

v4 source (surveyed 2026-07-06): `lib/services/chat-message/
courier-transport.service.ts` (340) + `lib/llm/courier/render-markdown.ts`
(278) + the paste resolver in `app/api/v1/chats/[id]/messages/[messageId]/
route.ts` (~100 of 415) + the orchestrator branch (~80 lines). The courier is
the manual-ferry transport: instead of calling a model, the turn is parked —
the full request is rendered as Markdown, persisted on a placeholder ASSISTANT
message, and the user pastes the reply back from an external LLM client.
**No model calls, no tools, no host I/O** — it is repos + string rendering, so
the whole unit is portable engine code.

Port (new `services::courier_transport` + `courier::render_markdown`):

1. **`renderCourierRequestAsMarkdown`** — full-bundle renderer: `#
   Instructions` header, `# System` section, `# Conversation` with speaker
   labels, `# Your turn` footer; newline collapse `\n{3,}` → `\n\n`;
   `trimEnd() + '\n'`; returns markdown + the union of referenced attachment
   descriptors. Byte-exact strings.
2. **`renderCourierDeltaAsMarkdown`** — delta renderer (`# Continuing the
   conversation` / `# New since your last reply`), no system section.
3. **`buildCourierDeltaEvents`** — fetch messages after the per-character
   checkpoint (`chat.courierCheckpoints[characterId]`, `{lastResolvedMessageId,
   resolvedAt}`): strict `createdAt <= resolvedAt` skip (equality matters),
   the checkpoint message itself excluded defensively, whisper filtering
   (surfaced only when the responding character is sender or target), speaker
   resolution with the EXACT staff label map (`lantern → 'The Lantern'`,
   `aurora → 'Aurora'`, `librarian → 'The Librarian'`, `concierge → 'The
   Concierge'`, `prospero → 'Prospero'`, `host → 'The Host'`, `commonplaceBook
   → 'The Commonplace Book'`, `ariel → 'Ariel'`; unknown → `[Staff: <x>]`;
   fallbacks `'User'` / `'Off-scene character'`), attachment metadata loading
   (file-lookup failure = skip + log, filename falls back to fileId, mime
   defaults `application/octet-stream`), dedup of attachments by `fileId`
   across full+delta bundles.
4. **`dispatchCourierTransport`** — mint ONE `nowIso` up front; always render
   the full bundle; delta mode when `courierDeltaMode !== false` AND a
   checkpoint exists; primary = delta else full, `pendingExternalPromptFull` =
   the full fallback only when delta is primary; the placeholder message
   (`role: 'ASSISTANT'`, `content: ''`, `attachments: []`,
   `pendingExternalPrompt` / `pendingExternalPromptFull` /
   `pendingExternalAttachments`, provider/model from the effective profile)
   through the ported `chats_messages::add_message`; then
   `chats.update({isPaused: true, updatedAt: nowIso})`; SSE order:
   `pendingExternalTurn` frame FIRST, then `done` with `pendingExternalTurn:
   true` (add both to `chat_events`, byte-exact); return `isPaused: true` so
   the ported turn chain halts (`should_chain_next` already stops on paused —
   verify, don't re-implement).
5. **The paste resolver** (`resolve-external-turn` + `cancel-external-turn`)
   as public service functions (the HTTP route is Phase-4 transport): verify
   placeholder (ASSISTANT + `pendingExternalPrompt` present), set `content =
   replyContent` + null the three pending fields, unpause + bump
   `lastMessageAt`/`updatedAt`, advance the checkpoint
   `courierCheckpoints[characterId] = {lastResolvedMessageId: messageId,
   resolvedAt}`, then the fire-and-forget background triggers (memory
   extraction / danger classification / summary check — reuse the ported
   `queue_service` + finalizer trigger logic; awaited per the watermark
   precedent).
6. **Close the orchestrator courier gate**: the `is_courier` branch
   (`orchestrator.rs:550`) currently errors "courier transport not ported" —
   replace with the real dispatch (skipping tool build exactly as v4:
   `resolvedToolMode='native'` unused, no instructions — already faithful).

Marshaling check: `chats.courierCheckpoints` and the three
`pendingExternal*` message columns — confirm they are in the ported chats /
chat_messages marshaling (they postdate some sub-units; if missing this is a
DRIFT item — extend the marshaling first with its own corpus rows, the
answer-confirmation-columns precedent).
