## Mandate

v4 has fixed the four defects this port found on the backup/restore/import path.
All four were **ruled deliberate v5 divergences** (2026-07-24 and 2026-07-25) on
the grounds that they sit on the data-loss path, and all four are asserted in
**both directions** so an upstream fix cannot pass unnoticed. Those assertions
will now fail. **That is the tripwire working, not a regression.**

This lane's job is to **prove convergence and retire the divergences** — and,
where convergence is not exact, to say so precisely rather than quietly moving
v5 to match.

**The one thing this lane must not do is assume.** v4's own
`docs/developer/found-bugs.md` status table (`:335-341`) states all four as
"Converged", including *"files run after 22a on both sides"* — but that is v4's
claim **about v5**, written without running v5. The differential is what proves
it. Where v4's claim and the diff disagree, the diff wins and the disagreement
is the finding.

**Must NOT touch:** anything the three chat lanes own — `services/chat_*`,
`api/salon.rs`, `db/chats*.rs`, `api/types.rs`, `api/engine.rs`, and all of
`apps/web/**`. This lane needs none of them.

## The differential requirement, restated

This lane writes almost no new port code — its product is **proof**. The
equivalence tests already exist and already drive v4's REAL `lib/` code; the
work is regenerating them at the new baseline and converting asserted
divergences into asserted equalities.

That makes one failure mode dominant and it is worth naming: **a differential
that passes because its oracle is stale proves nothing.** Read
`oracle-regen-silent-stale-pass` before you start — an erroring oracle builder
leaves the OLD NDJSON in place and the run goes green. **Grep each regenerated
NDJSON for the new behavior before trusting a pass** (for bug 4, the truncation
error text; for bugs 1–3, non-zero mount-point / file-link / file rows on the v4
side, which is the whole point of the fix).

Other notes that apply: `oracle-jest-testtimeout` (these are slow tier-2
families), `oracle-fire-and-forget-tails`, `harness-corpus-shape-constants-rot`,
and `p4.9g5-restore-execute-round` (this lane's direct predecessor — read its
record for the normalizers, the per-table minted labels, and the
`restore_preview_writes_nothing` arm).

**v4's tree is clean at `c1507f47`**, so oracles regenerate straight from
`~/source/quilltap-server`. Pin a detached worktree only if it goes dirty again
(`oracle-regen-pinned-v4-worktree`).
