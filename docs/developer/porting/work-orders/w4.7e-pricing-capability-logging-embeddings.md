## What to port

1. **The pricing fetcher** (`services::pricing_fetcher`): the fetch itself
   is an injected `PricingFetch` seam (the raw response JSON handed in);
   port the parse + cache decisions pure with `now_ms` injected:
   - The public-models parse (`fetchOpenRouterPublicPricing` 62–113):
     `GET https://openrouter.ai/api/v1/models`; per-token STRING prices via
     `parseFloat(String(x || '0')) * 1_000_000` (keep JS parseFloat
     semantics — garbage → NaN propagates), `context_length ?? null`,
     `architecture?.modality?.includes('image')` → supportsVision,
     `supported_parameters.some(p => p==='tools'||p==='tool_choice')` →
     supportsTools.
   - Cache mechanics: 24 h TTL (`CACHE_TTL_MS`), the 5-min NEGATIVE cache
     (`openRouterPublicFetchFailureAt` — return `[]` inside the window,
     reset to null on success), store-only-when-nonempty, all in-memory
     process-global (the `housekeeping_outcome_cache` OnceLock precedent).
     The 3 s fetch timeout is host-timing (W4.3 precedent — no timer).
   - `PROVIDER_TO_OPENROUTER_SLUG` (OPENAI/ANTHROPIC/GOOGLE/GROK) +
     `getOpenRouterPricingForModel`'s exact-then-fuzzy (substring either
     direction) match; `findCheapestAvailableModel`'s requireVision/
     requireTools filters; `getPricingCache`/`refreshPricingCache` keyed
     off `updatedAt` age.
   - ⚠️ TWO OpenRouter paths with DIFFERENT casings: the public path reads
     snake_case (`supported_parameters`/`context_length`); the
     authenticated SDK path (`fetchOpenRouterPricing` 215–263) reads
     camelCase (`supportedParameters`/`contextLength`). Check
     `fetchProviderPricing`'s dispatch to see which are reachable and port
     each reachable path parsing ITS OWN shape — do not unify. The Ollama
     models fetch (`fetchOllamaModels`) rides the same seam.
   - Close the finalizer's **cost-estimation** evidence seam: port
     `estimateMessageCost`'s cascade (OpenRouter cache → registry →
     pricing cache → public per-model estimate when provider ≠ OPENROUTER)
     with the source tags (`openrouter`/`registry`/`fallback`/
     `openrouter-estimate`/`unavailable`) — the finalizer's recorded
     estimation seam becomes the real cascade over an injectable fetch.

## Differential plan

- **Pricing/capability** (`pricing_fetcher_equivalence`, tier-1): the
  oracle mocks `global.fetch`/the SDK with committed payloads and drives
  v4's real exports; the Rust side injects the same payloads + a stepped
  clock. Rows: the parse (string prices incl. a garbage-string NaN row),
  TTL expiry, the negative-cache window (inside/outside/reset-on-success),
  slug fuzzy matching both directions, `findCheapestAvailableModel`
  filters, `checkModelSupportsTools` matrix (openrouter hit/miss/
  cache-error, fallback providers, unknown → true), and the
  `estimateMessageCost` cascade with each source tag banked.
- **logLLMCall**: `request_prefix_hashes_equivalence` (tier-1 — sorted-key
  stableStringify rows incl. nested objects/arrays + non-ASCII) + a tier-2
  llm_logs row diff through a REAL call site: regenerate ONE cheap-LLM
  differential (`compression_tier3` is the smallest) with logging
  un-mocked and the `llm_logs` table dumped (minted id/createdAt
  placeholdered; `durationMs` pinned via injected clock both sides). Then
  regenerate the other closed-call-site oracles (`danger_gatekeeper`,
  `answer_confirmation`, `image_generation`, `primary_stream`) the same
  way — **one at a time, each its own commit-able step**; if the cascade
  threatens the session, land the writer + the compression regeneration
  and list the rest as explicit follow-ups in CLAUDE.md (do not leave an
  oracle half-regenerated).
- **Embeddings** (`embedding_wire_equivalence`, tier-1): drive each v4
  plugin provider with fetch/SDK mocked to committed payloads (the W4.7b
  recorder precedent — `record-embedding-fixtures.mjs`); diff the built
  request (method/url/headers/body bytes) + the parsed result. Bank: the
  dimensions-omitted vs present bodies, the ollama 404-legacy fallback +
  both NaN-guard messages + the num_ctx matrix (found/missing/ceiling/
  cache-hit), the openrouter base64 vs array paths, and an empty-input
  ollama reject that never reaches the wire.
- **Builtin** (`tfidf_vectorizer_equivalence`, tier-1): drive the real
  plugin vectorizer over committed fit-state + query corpus.

## Watch-outs

- `parseFloat` on price STRINGS — reproduce JS semantics (leading-number
  prefix parse, NaN on garbage), not Rust `str::parse`.
- The two OpenRouter response casings are a latent v4 divergence — port
  both faithfully, never "fix" by normalizing.
- `stableStringify` sorts keys; every other ported serializer preserves
  insertion order. Name the Rust helper distinctly so nobody reuses the
  wrong one.
- `isLoggingEnabled` logs BY DEFAULT (missing settings and read errors
  both → enabled).
- The pricing caches are process-global in-memory — same OnceLock pattern
  as the housekeeping outcome cache; tests must reset or key by instance.
- v4's `Logger.logLLMCall` (`lib/logger.ts:208`) is an UNRELATED app-log
  method — do not conflate with the DB service.
