## Shared contract (BINDING — identical in P4.D57)

The Brahma Console settings surface this card consumes:

**Dispatch (CoreRequest / Response):**

- **Get** — `Request` variant `BrahmaConsoleSettings`, wire `type:
  "brahmaConsoleSettings"`, no fields. Response variant `BrahmaConsole(Value)`,
  wire `type: "brahmaConsole"`, body `{ "maxAgentTurns": <int> }`.
- **Set** — `Request` variant `BrahmaConsoleSettingsUpdate`, wire `type:
  "brahmaConsoleSettingsUpdate"`, field `maxAgentTurns` (absent = keep current,
  null → 400, number → validate). Response variant `BrahmaConsole(Value)`
  carrying the STORED `{ "maxAgentTurns": <int> }`.

**REST edge (v4-URL parity, not used by the SPA):** `GET/PUT
/api/v1/settings/brahma-console`, body `{ "maxAgentTurns": <int> }`, 400 on
out-of-range/null.

**Semantics:** `maxAgentTurns` is an integer in **[5, 200]**, default **50**.
