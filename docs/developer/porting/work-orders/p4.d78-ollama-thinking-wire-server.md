## The drift, classified (surveyed FRESH 2026-08-15 at `aa464abf`)

`d9c5a1c7`, 27 files, +1,115/−113. The wire-half mechanics, from the
diff (the host-half — `lib/llm/cheap-llm.ts` + eight call sites — is
P4.D79's):

- **`plugins/dist/qtap-plugin-ollama/think-parser.ts` (new, 140 l).**
  `ThinkTagStreamParser`: a stateful streaming splitter. `push(delta)`
  returns displayable text; `<think>…</think>` interiors accumulate on
  `.reasoning` (raw, monotonic). Mechanics to carry exactly:
  `partialTagSuffixLength` holds back a partial tag at a chunk
  boundary (longest strict prefix of the tag that the text ends with);
  the **swallowed-opening-tag** rule — a `</think>` arriving before
  any think block AND before any visible output means everything ahead
  of it is reasoning (`orphanEligible = !sawThinkBlock &&
  !emittedVisible`; once real content has been emitted the rule is off
  the table); `flush()` releases the held tail exactly once — inside
  an unterminated think block the tail counts as reasoning and returns
  `''`; `sanitize()` drops leading whitespace between a consumed think
  block and the first visible character (`replace(/^\s+/, '')`), only
  while `!emittedVisible && sawThinkBlock` — no-think responses pass
  byte-for-byte. One-shot `extractThinkBlocks(content)` =
  `push + flush` for the non-streaming path.
- **`provider.ts` non-streaming** (`sendMessage`): body gains
  top-level `think: enableThinking` (ALWAYS present — `think: false`
  when off) and `options.num_ctx` from `resolveNumCtx` (undefined keys
  dropped by `JSON.stringify`). `resolveEnableThinking`:
  `profileParameters.enable_thinking === true || === 'true'`.
  `resolveNumCtx`: `profileParameters.num_ctx` number|string coerced
  via `Number`, `Number.isFinite(n) && n > 0 ? Math.floor(n) :
  undefined`. On a non-ok response whose body text matches `/think/i`
  AND the body still carries `think`: **retry ONCE with `think`
  deleted** (`isThinkRejection`), then fail with the ordinary
  `Ollama API error: <status> <text>` if still non-ok. Response parse:
  `extractThinkBlocks(message.content)` + `message.thinking` (native);
  `reasoningContent = nativeThinking + inlineReasoning`, attached to
  the response ONLY when non-empty (`...(reasoningContent ? … : {})`).
- **`provider.ts` streaming** (`streamMessage`): same `think` +
  `options.num_ctx` on the body; the same retry-once-without-think
  wrapped around the stream OPEN (each attempt re-arms the first-byte
  timer — v4 refactors the open into `openStream()`). Per NDJSON
  line: `message.thinking` deltas append to `reasoningSoFar`; content
  deltas go through the shared `ThinkTagStreamParser`, whose new
  reasoning is spliced by index (`thinkParser.reasoning.slice(
  inlineReasoningSeen)`); **`reasoningContent` is emitted
  CUMULATIVELY** (the full thinking-so-far) on a chunk with
  `content: ''` whenever reasoning grew; visible text still counts
  `chunkCount`/`totalContent` and is NOT yielded when empty. At
  `done`: `flush()` — the tail (if any) yields as one more content
  chunk BEFORE the final chunk; the final chunk gains
  `...(reasoningSoFar ? { reasoningContent: reasoningSoFar } : {})`.
- **`index.ts`**: `capabilities.toolUse: false → true` (the
  per-profile Allow Tool Use checkbox stays the gate); a new
  `getProviderOptionsSchema` returning the `enable_thinking` boolean
  row (v5 does NOT model optionsSchema — see Tier 3). Manifest
  version `1.0.40 → 1.0.41`.
- New v4 suite `__tests__/unit/plugins/ollama-thinking.test.ts`
  (323 l): parser chop tests, native-channel streaming, retry
  fallback, swallowed-open reproduction, num_ctx wire format — the
  oracle-import surface for this lane's differentials.
