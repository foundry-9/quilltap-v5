## The differential requirement, restated

This lane ports nothing, so its differential obligation is inverted:
**it must not change what any differential PROVES.** Recipe repairs
change how oracles are produced, not what they contain — after each
repair, run the family end-to-end (`--run`) and confirm green (or the
documented ruled-red → pinned-green transition for R1). Freshness-check
every regenerated NDJSON (the stale-pass trap). Any repair that changes
a family's case list, fixture bytes, or assertion set is out of scope —
that's a port change wearing a maintenance hat.
