   build into `/tmp` per the tier-2 recipes). Cases must cover: all five
   types, type filtering, limit cap 50, offset paging + `hasMore`,
   `countsByType` before pagination, min-2 validation arm, and the sort.

   `<main>` counterpart (`shell.ts:177-178`), using the already-ported CSS;

   the provider — signals-based, matching how v5 handled such contexts

   sidebar-footer stopgap at `shell.ts:137-138` RETIRES.

   custom event, or the same DOM event — match v4's mechanism unless Angular

   of v4's 19 sites (enumerate in the lane record).

   localStorage key, constants, matchMedia gate, root CSS vars +
   `data-full-width`, cross-tab storage sync; the `72rem`→`75rem` narrow
