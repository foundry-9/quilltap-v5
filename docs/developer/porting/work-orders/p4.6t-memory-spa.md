## Shared contract (BINDING — identical in p4.6s / p4.6t / p4.6u)

### New Request variants (wire `type` names; Rust mirrors in PascalCase)

Memories — list/read/write:
- `memoryList {characterId, search?, minImportance?, source?, sortBy?,
  sortOrder?, limit?, offset?}` → `{memories: (MemoryDto &
  {tagDetails})[], count, totalCount}` (two v4 code paths: `limit`
  present = paginated; absent = legacy-all with totalCount === count)
- `memoryGet {memoryId}` → `{memory}` (+ tagDetails)
- `memoryCreate {memory}` → `{memory}` (gate-driven; embedding-failure
  is a server-error refusal, no row)
- `memoryUpdate {memoryId, memory}` → `{memory}` (NO re-embed — v4
  parity)
- `memoryDelete {memoryId}` → `{success: true}`
- `memoryDeleteByChat {chatId}` → `{success, chatId, deletedCount}`
- `memorySearch {characterId, query, limit?, minImportance?, minScore?,
  source?}` → `{memories: (…& {score, usedEmbedding, tagDetails})[],
  count, query, usedEmbedding}`
- `memoryCountByChat {chatId}` → `{chatId, memoryCount}`
- `memoryByMessage {messageId}` → `{memoryCount, isSwipeGroup,
  swipeCount, memories: [{id, summary, characterId, importance}]}`
  (the trimmed shape)

Housekeeping:
- `memoryHousekeepPreview {characterId, maxMemories?, maxAgeMonths?,
  minImportance?, mergeSimilar?}` → the preview result
- `memoryHousekeep {options}` (v4 `housekeepingOptionsSchema` incl.
  `dryRun`) → `{success, dryRun, result: {deleted, merged, kept,
  totalBefore, totalAfter, deletedIds, mergedIds, details?}}`
  (`details` only when dryRun)
- `memoryHousekeepSweep {}` → `{success, jobId}`
- `memoryHousekeepingConfigGet {}` → the config with v4's default
  injection (`{enabled:false, perCharacterCap:2000,
  perCharacterCapOverrides:{}, autoMergeSimilarThreshold:0.90,
  mergeSimilar:false}`)
- `memoryHousekeepingConfigSet {config}` → merge-patch echo
- `memoryCharacterCounts {}` → the `{id, name, memoryCount}` list,
  memoryCount desc (exact envelope pinned by lane A's oracle)

Embeddings / backfill:
- `memoryEmbeddingStatus {characterId}` → `{total, withEmbeddings,
  withoutEmbeddings, percentComplete, embeddingProfileConfigured,
  embeddingProfileName}`
- `memoryGenerateEmbeddings {characterId, batchSize?}` → v4's shape
- `memoryRebuildIndex {characterId, confirm: true}` → v4's shape
- `memoryBackfillProgress {}` → `{remaining, inFlight}`
- `memoryBackfillStart {characterId?, batchSize?}` → `{success,
  enqueued, remaining, message}`

Configs (all merge-patch on Set):
- `memoryExtractionLimitsGet {}` / `memoryExtractionLimitsSet {config}`
- `memoryRecallConfigGet {}` / `memoryRecallConfigSet {config}`
  (`scopePolicy: 'down-weight'|'exclude'`, `expandRelated`)
- `memoryExtractionConcurrencyGet {}` /
  `memoryExtractionConcurrencySet {concurrency}`

Regenerate + per-chat:
- `memoryRegenerateAllStatus {}` → `{inFlightFanOut, inFlightWipes,
  inFlightExtractions, inFlight}`
- `memoryRegenerateAll {}` → `{success, jobId, isNew, cleared, message}`
- `chatQueueMemories {chatId}` → `{success, jobCount, chatId,
  turnCount}`

NO variants this round (enumerated deferrals): the
`extract-memories-dry-run` stream, `memoryDedupPreview`/`memoryDedup`,
embedding-profiles management, conversation-summaries regeneration.

Envelope rule: variant and param NAMES above are binding at name level;
exact response envelopes/nullability are pinned by lane A's oracle
(expect the P4.6p pattern — route reads may omit null nullables while
create/update echo them AS null) and reconciled name-for-name at
unification.

### MemoryDto (read shape)

`{id, userId, characterId, content, summary, keywords: string[],
tags: string[], importance, source: 'AUTO'|'MANUAL', chatId|null,
projectId|null, aboutCharacterId|null, sourceMessageId|null,
witnessedContext|null, lastAccessedAt|null, reinforcementCount,
lastReinforcedAt|null, relatedMemoryIds: string[],
reinforcedImportance, createdAt, updatedAt}` + derived `tagDetails`
(tag rows) on list/get/search. Whether `embedding` rides the JSON echo
is pinned by lane A's oracle — lane B must NOT rely on it.

### Error arms the SPA surfaces

Memory/character `notFound` 404s; create-gate embedding failure →
server error (the SPA shows v4's toast fallback copy); `confirm`
literal-true violation → 400; the config schemas' range violations →
400.
