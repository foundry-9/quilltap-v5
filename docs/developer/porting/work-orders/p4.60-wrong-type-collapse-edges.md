## Mandate

Adjudicate, one by one, the web-edge sites P4.57's tier-2 survey enumerated
as the **wrong-type-collapse class**: edges that read body keys with
`.and_then(Value::as_str)` / `as_bool` / `as_array`, which collapses THREE
inputs into `None` — absent, explicit `null`, and **a present-but-wrong-typed
value**. The third is the dangerous one: a wrong type silently becomes "the
caller didn't say" instead of reaching a validator that would refuse it.
**None of these is pre-claimed as a defect** — P4.57 explicitly said each
needs its v4 route read first. This lane reads each v4 route, measures v5's
current behavior, fixes where divergent (decoding through the `Request` enum
per the standing rule — memory `edge-must-decode-through-the-request-enum`;
`double_option` where a tri-state is load-bearing, the P4.D57/Taboo lesson),
and pins every verdict — divergent-fixed arms red-first, faithful verdicts as
recorded equalities in the lane record.

**Must NOT touch:** anything P4.59 or P4.61 owns; `text_replacements_routes.rs`
and `profile_routes.rs` (P4.57 measured them done/correct);
`llm_logs_routes.rs:53–66` (query parameters — P4.57 listed them only so a
future sweep doesn't re-flag them; re-flag nothing). Guard-order discipline:
where a fix adds validation, match v4's check ORDER (the `group_update`
parse-before-find lesson — a 400 where v4's find-first answers 404 is a new
divergence, not a fix).
