Deliver the wardrobe **server** surface v5 never got: the chat-scoped
outfit read and the seven-mode equip route, the wardrobe-transfers pair,
the GLOBAL archetype CRUD tier, and (tier 2) the two avatar verbs —
each as a differential dispatch port over v4's real route handlers, with
REST edges, a NEW committed fixture family, oracle cases, and a route

§4). This lane touches no SPA file, no `tools/**`, no `pascal/**`, no
`api/photos.rs`/`photos_routes.rs`, and — per Ownership — **no
`quilltap-host/**`**. v4's user-facing strings (error messages, refusal
wording, slot labels) carry verbatim; they are wire payload, not prose
to improve.

**Why this is a LANE and not a rider.** The M6 backlog sized `p4.9f` as
a single lane on the assumption that the wardrobe verbs already existed
and only the dialog was missing. A fresh survey (2026-07-18) found
**seven missing verb families** — the whole chat-equip route, the whole
transfers route, the whole global archetype tier, and both avatar verbs.
What makes this still tractable in one round is the other half of the
same survey: **the service and db tiers underneath are largely already
ported.** `services::wardrobe_transfers` has BOTH halves of the
transfers route; `db::chats_outfits` has every equipped-outfit
primitive; `wardrobe.rs` has the wear/replace/composite/describe/hash

the prompt builder and the job handler. So this lane is **mostly
dispatch-and-differential over landed Rust** — which is precisely why it
can run in parallel with the SPA half instead of blocking it.

## The differential requirement, restated

**Every ported unit arrives with an equivalence test against the v4
oracle** — an oracle case that imports v4's **REAL** `lib/` and **real
route handlers** at `616930db` (never a reimplementation), drives a
fixed deterministic corpus, emits NDJSON, and is diffed field-by-field
by the Rust suite. These are **tier-2 structural DB diffs**: normalize
the legitimately-nondeterministic fields only — timestamps, generated
UUIDs (via a remap), LLM text — and nothing else.

Closest recipes to follow:

- **`crates/quilltap-web/tests/photos_routes_equivalence.rs`** — the
  route-corpus shape this lane's differentials should mirror (one shared
  multi-case JSON, REST edge + dispatch both exercised).
- **`crates/quilltap-harness/tests/wardrobe_transfers_tier2_equivalence.rs`**
  (`:478`) — the transfers half already has its structural-diff
  vocabulary; extend that idiom rather than inventing one.
- **The `p4d7` memory's lesson: direct-drive differentials beat jest
  route oracles.** Prefer driving the v4 handler function directly over
  standing up a jest route harness, unless the route's own parsing is
  what's under test.

Two traps to plan around explicitly:

- **`oracle-fire-and-forget-tail`** — a mutating case's stray promises
  poison the NEXT case. If reordering the corpus moves the failure, it
  is contamination, not a port bug. Order mutating cases last, or await
  the tails.
- **`oracle-regen-silent-stale-pass`** — an erroring builder leaves the
  OLD fixture in place and the suite goes green on stale data. **Grep
  the emitted NDJSON for a row you know is new** before trusting green.
