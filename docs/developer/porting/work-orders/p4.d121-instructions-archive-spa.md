## Shared contract part A (BINDING — identical text in `p4.d119-wardrobe-instructions-server.md`)

1. **Eight dispatch verbs** (serde camelCase over the Request enum),
   named after the existing per-scope wardrobe verb families:
   - `characterWardrobeInstructionsGet { characterId }` /
     `characterWardrobeInstructionsSet { characterId, instructions }`
   - `groupWardrobeInstructionsGet { groupId }` /
     `groupWardrobeInstructionsSet { groupId, instructions }`
   - `projectWardrobeInstructionsGet { projectId }` /
     `projectWardrobeInstructionsSet { projectId, instructions }`
   - `wardrobeInstructionsGet {}` / `wardrobeInstructionsSet
     { instructions }` (Quilltap General)
   `instructions` is `string | null` and REQUIRED (v4's
   `z.string().nullable()`, not optional — an absent key fails
   validation; decode through the Request enum, never a hand-built
   variant; memories: `edge-must-decode-through-the-request-enum.md`,
   `dispatch-verb-ignores-unknown-fields.md`).
2. **Success body** on every arm: `{ instructions: string | null }` —
   the SET echo is the TRIMMED string, `null` when cleared.
3. **Error arms** (v4's envelopes): invalid body → flat
   `Validation error` 400; 404 `Character not found` / `Group not found`
   / `Project not found`; character SET on an archived character → 409
   `Character is archived; dressing instructions cannot be edited`
   (GET is NOT tombstoned — 200); vault-less character SET with content
   → 500 `Character has no vault to hold dressing instructions`
   (cleared → 200 no-op); group/project store-ensure failure → 500
   `Failed to ensure group document store` / `Failed to ensure project
   document store`; unprovisioned General SET with content → 500
   `Quilltap General store is not provisioned yet` (cleared → 200
   no-op).
4. **The client field hint** (P4.D121 lands it in
   `prompt-field-hints.ts`, byte-exact, between `groupInstructions` and
   `roleplayTemplatePrompt`): label `Dressing Instructions`; helper and
   example verbatim from v4's `field-hints.ts:103-109` including the
   curly quotes (U+201C/U+201D), curly apostrophes (U+2019), and the em
   dash — the lane transcribes from `git show b86bb1a5:components/
   prompt-fields/field-hints.ts`, never from this order.
5. **UI strings** (P4.D121): `Dressing Instructions`, `Consulting…` /
   `On file` / `None on file` (U+2026), `Save Instructions` / `Saving…`,
   toasts `Dressing instructions saved` / `Dressing instructions
   cleared` / `Failed to save dressing instructions`.
