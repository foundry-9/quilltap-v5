## The drift, classified (surveyed 2026-08-22, fresh at `d5830439`)

A new bundled provider `qtap-plugin-nanogpt` (1.0.0 → 1.0.1): NanoGPT's
OpenAI-compatible gateway at **`https://nano-gpt.com/api/v1`** across all
three capabilities — chat (`/chat/completions`, streaming, tools, JSON
response formats, dual-dialect reasoning), images (OpenAI-compatible
route, `b64_json` pinned + URL-download fallback, honest Fetch Models via
`/image-models`), embeddings (`/embeddings`, discovery via
`/embedding-models`) — plus a `reasoning_effort` options schema, a
`thinkingTurnRule`, and per-model thinking facts for the catalogued
`anthropic/claude-sonnet-5:thinking`. The embedding-profile provider enum
widens (`OPENAI, OLLAMA, OPENROUTER, NANOGPT, BUILTIN`). Everything rides
already-ported v5 substrates: the manifest registry, `ProviderKind`, the
chat-completions builder family, the `chat_completions_sse` decoder, the
P4.D97 thinking-turn machinery, the P4.9H2A embedding-profiles family,
and P4.D100's image discovery + download seam.
