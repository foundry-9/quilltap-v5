## Survey-verified starting points (2026-07-31)

**v4 `lib/toast.tsx` (151 LOC, read today):**

- Imperative module-level API, no host component: `ensureContainer()`
  lazily appends a `<div role="toast-container">` to `document.body` —
  `position:fixed; bottom:20px; right:20px; zIndex:50;
  pointer-events:none; display:flex; flex-direction:column; gap:10px;
  max-width:400px` — and mounts a React root into it.
- `showToast(message, {duration = 3000, type = 'info'})` pushes
  `{id, message, type, duration}`, re-renders the stack, auto-removes via
  `setTimeout(duration)`, returns the id. No dismiss button, no hover
  pause, no dedup.
- Per-type classes (`getToastStyles`): success `bg-green-500
  dark:bg-green-600` / border green-600/700; error red; warning yellow;
  info blue. Toast body: `border … text-white px-4 py-3 rounded-lg
  shadow-lg pointer-events-auto` + a `slideInUp 0.3s ease-out` entry
  animation.
- Exports: `showSuccessToast` / `showErrorToast` / `showWarningToast` /
  `showInfoToast(message, duration?)`, plus `ToastType`.
- **107 files** under `components/`+`app/`+`lib/` import the helpers at
  `ff12f491` (`grep -rl "showSuccessToast\|showErrorToast\|showInfoToast\|
  showWarningToast"`).
