## The defect (localized 2026-07-23 from a server-stderr backtrace, RUST_BACKTRACE=1)

`thread '<unnamed>' panicked … user-provided comparison function does not
correctly implement a total order`, in
`quilltap_core::memory_injector::format_dynamic_memory_head` under
`build_context → process_message → spine::run_send`, on a real Salon send.
The turn dies. **Because `run_summary_check` runs at the END of
`process_message` (`orchestrator.rs:2372`), this panic also kills the
context-summary fold gate before it is evaluated — it is the leading
candidate cause of finding #26** (two panics were observed the same evening
the fold never fired). This lane fixes the panic; #26's re-check belongs to
the post-rewrite dogfood run, once summaries can actually complete.

**Not NaN.** The epsilon-threshold comparators are non-transitive on
ordinary finite values: "if the weight gap exceeds 0.05 compare weights,
else compare scores" gives, for weights 0.00/0.04/0.08, a=b and b=c but
a<c. A standalone repro panics reliably at **n ≥ 50** memories and never at
n = 20 — fixture slates are small, real recall slates are not. v4 carries
the IDENTICAL comparator; **V8's TimSort does not validate the comparator,
Rust's driftsort does** — the panic is a Rust-runtime artifact of running
v4's own (broken-in-both) comparator on a big enough slate.

## The ruling (RULED 2026-07-23: arm (a), the non-validating stable merge sort)

The comparator itself cannot be fixed — it is v4's, and changing its
decisions would change ranking output. The choice is which SORT runs it:

- **(a) A non-validating stable merge sort (RECOMMENDED).** ~40 lines, no
  panic by construction. For any SELF-CONSISTENT comparator every stable
  sort produces identical output, so this is v4-identical everywhere the
  comparator forms a total order — divergence from V8 is possible only
  inside the contradictory region, where BOTH engines produce
  arbitrary-but-deterministic garbage that nothing semantic depends on and
  no committed differential slate currently reaches (the harness slates
  are < 50; verify and record this while landing). If a future oracle case
  ever lands in the contradictory region, the diff trips loudly and the
  decision can be revisited with evidence in hand.
- **(b) Port V8's TimSort.** Exactly faithful even in the contradictory
  region, at the cost of several hundred lines of subtle sort code (runs,
  galloping, minrun) that would itself need heavy testing — and whose
  faithfulness only matters where the comparator is already broken in v4.
