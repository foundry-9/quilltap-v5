### Quirks the port must not miss

1. `update-settings` caps are nullish — explicit null CLEARS a cap;
   absent leaves it. Do not collapse the two.
2. `clampedDestructive` echoes whether the user's `always_refuse`
   policy clamped the flag off.
3. The status snapshot's defaults: `budgetExcludeCacheHits` default 1,
   `runDestructiveToolsAllowed` default 0.
4. The listing sort is two-key (runState order, then updatedAt desc)
   and the runState order is v4's literal array — pin it.
5. Ad-hoc rooms auto-start at creation (already ported); cron rooms
   wait for the scheduler — the SPA never starts a fresh cron room
   itself.
6. Badge budget readout priority is tokens → turns → time; the 1s
   tick is CLIENT-side only (no polling amplification).
7. The settings card's poll filter differs from the badges' (cron
   rooms always shown vs idle/running/paused only) — two filters, not
   one.
