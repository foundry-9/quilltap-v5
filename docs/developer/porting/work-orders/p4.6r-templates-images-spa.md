## Shared contract (BINDING — identical in p4.6p / p4.6q / p4.6r)

### New Request variants (wire `type` names; Rust mirrors in PascalCase)

Roleplay templates:
- `roleplayTemplateList {}` → **bare JSON array** of RoleplayTemplateDto
  (built-in-first, then `name` localeCompare [ICU4X en-US])
- `roleplayTemplateCreate {template}` → the created RoleplayTemplateDto
- `roleplayTemplateGet {templateId}` → RoleplayTemplateDto (read-time
  renderingPatterns auto-gen, non-persisted)
- `roleplayTemplateUpdate {templateId, template}` → the updated Dto
- `roleplayTemplateDelete {templateId}` → `{success: true, deletedId}`

Image profiles:
- `imageProfileList {sortByCharacter?}` → `{profiles, count}` (plain:
  default-first then createdAt DESC, each + `apiKey` summary + enriched
  `tags`; sortByCharacter: adds `matchingTags` + `matchingTagCount`,
  tag-count DESC with v4's default-last tie-break; the
  `sortByUserCharacter` param's server behavior is pinned by lane A's
  oracle and reported at unification)
- `imageProfileCreate {profile}` → created profile + `apiKey` (tags raw
  `[]`)
- `imageProfileGet {profileId}` → profile + `apiKey` + enriched `tags`
- `imageProfileUpdate {profileId, profile}` → updated + enrichment
- `imageProfileDelete {profileId}` →
  `{message: "Image profile deleted successfully"}`
- `imageProviderList {}` → `{providers: [{value, label, defaultModels,
  apiKeyProvider, legacyNames}], count}`
- Refusal-armed (loud, unless lane A's tier-2 stretch lands the wire
  pair): `imageProfileGenerate`, `imageProfileValidateKey`,
  `imageProfileListModels`.

Global mount points:
- `mountPointList {}` → `{mountPoints: [DocMountPoint &
  {embeddedChunkCount}]}` (createdAt DESC)
- `mountPointGet {mountPointId}` → `{mountPoint: {…,
  embeddedChunkCount, capabilities}}`
- `mountPointCreate {mountPoint}` → `{mountPoint, warning?}`
- `mountPointUpdate {mountPointId, mountPoint}` → `{mountPoint}` (PATCH
  semantics; no count/capabilities on the echo)
- `mountPointDelete {mountPointId}` →
  `{message: "Mount point deleted successfully"}`
- The mount-point action verbs get NO variants this round.

### Bags (field-level pins from v4 @ `a7b1398d`)

- `roleplayTemplateCreate.template`: `{name (required, trimmed, ≤100),
  description? (≤500, trimmed, falsy→null), systemPrompt (required),
  narrationDelimiters (required: non-empty string | [open, close] both
  non-empty), delimiters? (TemplateDelimiter[]), renderingPatterns?,
  dialogueDetection? (falsy→null)}` — hand-validation messages verbatim
  (lane A's survey); auto-regen when renderingPatterns absent/empty and
  (narration)delimiters present.
- `roleplayTemplateUpdate.template`: v4's `updateRoleplayTemplateSchema`
  (all-optional: name 1–100, description ≤500 nullable, systemPrompt
  min 1, tags uuid[], delimiters, renderingPatterns, dialogueDetection
  nullable, narrationDelimiters string|tuple). Built-in guard → 403.
- `imageProfileCreate.profile`: `{name (required), provider (required,
  registry probe), apiKeyId? (must resolve → else 404), baseUrl?
  (''→null), modelName (required), parameters? (object, key order
  preserved), isDefault? (true → unset all other defaults),
  isDangerousCompatible?}`.
- `imageProfileUpdate.profile`: per-field gated; explicit `apiKeyId:
  null` clears; `tags` NOT updatable.
- `mountPointCreate.mountPoint` / `mountPointUpdate.mountPoint`: v4's
  `createMountPointSchema` / `updateMountPointSchema` verbatim (incl.
  the basePath refine and the route-side pattern defaults).

### DTOs

- RoleplayTemplateDto: `{id, userId (null = built-in), name,
  description?, systemPrompt, isBuiltIn, tags: string[], delimiters:
  TemplateDelimiter[], renderingPatterns: RenderingPattern[],
  dialogueDetection?, narrationDelimiters: string | [string, string],
  createdAt, updatedAt}`. TemplateDelimiter is the kind-discriminated
  union `wrap` | `linePrefix` | `tagPrefix` (the P4.4u3 marshaling).
- ImageProfileDto: `{id, userId, name, provider, apiKeyId?, baseUrl?,
  modelName, parameters, isDefault, isDangerousCompatible, tags,
  createdAt, updatedAt}` + `apiKey: {id, label, provider, isActive} |
  null`; get/list enrich `tags` to `[{tagId, tag}]`; the
  sortByCharacter list adds `matchingTags` + `matchingTagCount`.
- DocMountPointDto: the 19 `DocMountPointSchema` fields +
  `embeddedChunkCount`; get adds `capabilities {canWrite, canDelete,
  canCreateFolder, canMoveIn, canMoveOut, canConvert}`.
