### The UI behavior spec (v4 `CharTypeaheadPlugin` + typeahead shell + pickers)

- `:` + ≥2 chars searches; menu lists matches; Enter or click inserts;
  a **closed** trigger (`:smile:`) inserts immediately without the menu;
  unicode's commit is a trailing space after a complete alias (`\to ` —
  inserts and KEEPS the space, per `insertSuffix`).
- Inserted characters are plain Unicode text — no nodes, no images, no
  trailing space (emoji); ONE undo restores the literal typed (`:smi`).
- No-open contexts: after `http://`, inside `10:30`, Windows paths, `:`
  alone or `:a`, `:)`; fenced code + inline code (via the shared
  `code-context.ts`); unicode additionally bails inside math spans
  (`bailInsideMath` + `math-span.ts`); markdown escapes never open
  (symbol names must start with a letter, so `\*`, `\_`, `\[` are safe);
  `$5 and \to ` works (currency shape).
- The dataset is fetched lazily on first trigger/picker open (`load.ts`
  semantics); a fetch failure leaves typing unaffected — the menu simply
  doesn't open. The space bar never triggers the unicode fetch
  (`mayTriggerLoad:false`).
- Pickers: a shared panel (v4 `CharPickerPanel`, 293 lines — search
  field + browsable grid + recents row), with thin emoji/Ω popover
  wrappers; toolbar buttons in the formatting toolbar. **Toolbar buttons
  are NOT gated by the settings toggles** — the flags govern the
  automatic trigger only.
- Case-sensitive aliases for unicode: `\phi` φ vs `\Phi` Φ (the
  `byAliasExactCase` map); code-point entry `→`/`\u+2192`/`\u{1D538}`
  resolves arithmetically (every character reachable, including ones
  curation dropped).

```ts
// code-context.ts — the shared "am I in code?" bail for every typing aid.
// v4's $isInCodeContext (bug 63): one helper so the bail lists cannot drift.
import type { EditorState } from 'prosemirror-state';

export function isInCodeContext(state: EditorState): boolean {
  const { $from } = state.selection;
  if ($from.parent.type === state.schema.nodes['code_block']) return true;
  const codeMark = state.schema.marks['code'];
  if (!codeMark) return false;
  if (state.storedMarks?.some((m) => m.type === codeMark)) return true;
  return $from.marks().some((m) => m.type === codeMark);
}
```
