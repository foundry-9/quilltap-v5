## Shared contract (BINDING — identical in P4.D65 / P4.D66 / P4.D67)

Names are law; v4 shapes at `ed8934f1`.

1. **Verb success shapes** (pinned in round 1, restated): archive →
   `{ archived: bool, archiveFileId: string|null, pruneComplete: bool }`;
   rehydrate → `{ rehydrated: bool, archived: bool, archiveBundleFileId:
   string|null, restored?: { memories, documents, blobs }, warnings:
   string[] }`. REST: `POST /api/v1/characters/{id}?action=archive|rehydrate`.
   The passphrase-unavailable 400 sentence: `The archive cannot be sealed:
   your passphrase has not been entered since Quilltap started. Unlock once
   (or restart and unlock), then archive again.` **Owner: P4.D65.**
2. The change-passphrase response gains `archives: { total, reencrypted,
   failures: [{fileId, filename, reason}] }`; `total: -1` = the sweep itself
   failed; a failed sweep does NOT fail the passphrase change. Passphrase-
   mismatch reason string: `does not open with the old passphrase — it
   predates an earlier passphrase change`. **Owner: P4.D65.**
3. The CLI consumes the REST verbs of rule 1 over HTTP and treats bundle
   bytes as the frozen `QTAPARC1` layout. `services/character_archive/
   crypto.rs` is FROZEN this round — neither lane edits it; P4.D66 links it
   read-only for offline decrypt. **Owner: P4.D65 serves; P4.D66 consumes.**
4. Three-key export carry on character records (`archivedAt`,
   `archiveFileId`, `archivedAvatarFileId`): absent column → absent key;
   NULL cell → present `null`. A bundle IS an export. **Owner: P4.D65.**
5. Files-delete guard envelope: `code: "ARCHIVE_BUNDLE_HELD"` +
   `characterId` + the sentence in P4.D65's survey; `force=true` bypasses.
   **Owner: P4.D65.**
6. Bug-56 sentences are byte-contractual: the three `explain()` messages
   (missing/denied/not-a-directory, with the containerized variants), the
   folder-create 409 carrying `BasePathUnavailableError.message`, and the
   store-create warning `` `${availability.message} The store was created,
   but scanning will fail until the path is reachable.` `` **Owner: P4.D67.**
7. `api/engine.rs` and `api/types.rs` are **P4.D65-only** this round.
8. Fixture ownership: the new `character-archive-*` family + the
   `system-data-*` mutation + the four archived-arm extensions = P4.D65;
   the mount families = P4.D67; the Tier R corpus = P4.D66. Committed
   fixtures extend by mutation, never rebuild.
9. SPA gate flip: **the unifier** flips `CHARACTER_ARCHIVE_SERVER_LANDED`
   in `apps/web/e2e/character-archive-flow.spec.ts` and runs the four
