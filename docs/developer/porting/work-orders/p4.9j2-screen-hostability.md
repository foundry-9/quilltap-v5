### §3 — seam semantics (BINDING)

- **Optional injection**: screens inject the tokens `{ optional: true }`;
  null ⇒ routed mode, behavior byte-identical to today. Lane J2's own gate
  is the UNCHANGED existing ng + Playwright suites.
- **Self-close**: a screen whose save/cancel/back should dismiss its tab
  injects `WORKSPACE_HANDLE` + `WORKSPACE_TAB_ID`; when both non-null,
  close the tab instead of navigating (v4 `useCloseSelfTab`).
- **Portals**: child-tab hosts register DOM nodes under
  `portalKey(kind, chatId, docId?)`; the Salon relocates its live pane
  ELEMENT into the registered node (DOM `appendChild` move — the component
  stays in the Salon's logical tree so PTY/editor state survives; v4 uses a
  React portal, the DOM-move is the Angular-idiomatic equivalent and the
  keep-alive spec must prove xterm survives the move). Opening a document /
  terminal in workspace mode spawns the child tab via
  `openTab(kind, payload, { parentTabId })`; closing the child tab toggles
  the mode off; closing the parent Salon tab cascades (reducer-side, J1).
- **Backdrop**: the Salon (and only actual background sources) reports
  `{ url, isSalon }` under its `WORKSPACE_TAB_ID`; clears on null/destroy.
  The host paints per the v4 arbitration rule.
- **`refreshTab`**: J2's blank standalone document uses it to swap in the
  server-named `filePath` (same docKey — identity stable).
