## Survey-verified starting points (fresh, 2026-08-27)

### The v4 Tooltip contract (`components/ui/Tooltip.tsx`, 240 lines — port from the post-commit file, never the prose)

- Constants `:33-37`: `VIEWPORT_MARGIN = 8`, `ANCHOR_GAP = 6`,
  `CLOSE_GRACE_MS = 120`.
- Props `:45-73`: `content`, `children`, `placement: 'top'|'bottom' =
  'top'`, `delay = 200`, `pinnable = false`, `interactive = false`,
  `className` (bubble), `anchorClassName` (anchor span).
- Anchor `:191-211`: ALWAYS a `<span class="qt-tooltip-anchor …">`
  wrapping the trigger (the CSS comment's "fallback wrapper" claim is
  wrong — there is no clone path; faithful port = always-a-span). Handlers:
  pointerenter → open after `delay`; pointerleave → close after
  `CLOSE_GRACE_MS` unless pinned; focus → open IMMEDIATELY; blur → close
  now unless pinned; click toggles pin only when `pinnable`.
- Positioning `position()` `:122-147`: measure anchor + bubble rects; flip
  top↔bottom when the preferred side would breach `VIEWPORT_MARGIN`;
  `top = a.top - b.height - ANCHOR_GAP` (or `a.bottom + ANCHOR_GAP`);
  horizontally centred then clamped to
  `[VIEWPORT_MARGIN, innerWidth - b.width - VIEWPORT_MARGIN]`; the coords
  setter is identity-stable to avoid a render loop under rAF.
- Two-pass measure `:150-152, :227`: bubble renders `visibility: hidden`
  until measured (v4 `useLayoutEffect`; the Angular analogue must measure
  after render — `afterRenderEffect`/`afterNextRender`, not constructor).
- Listeners while open `:156-185`: `scroll` (capture — inner scrollers) +
  `resize`, rAF-coalesced reposition; `keydown` Escape → closeNow;
  `pointerdown` (capture) closes a PINNED bubble when the press is outside
  anchor and bubble. All removed on close.
- Bubble `:213-233`: portal child of `document.body` (no wrapper);
  `role="tooltip"` **`aria-hidden="true"`** — the accessible name lives
  entirely on the trigger's own `aria-label`; there is NO
  `aria-describedby` and no id generation; wrapped controls must carry no
  `title` (native tooltip would double up). Attributes:
  `data-interactive` (when `interactive || pinned`), `data-pinned`,
  `data-placement`; inline `top/left/visibility`.
