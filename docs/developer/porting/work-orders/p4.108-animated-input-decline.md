### ⚠ One refinement of the ruling's wording, adopted here and reported to the human

The ruling says "a WebP whose VP8X chunk carries the animation bit". A
WebP with the bit set and exactly ONE `ANMF` frame is a still to sharp
(`metadata().pages = 1`; its `{animated:true}` output is a still WebP), so
v4 loses nothing there; declining it would add a second divergence with no
frame at stake. **This order detects by FRAME COUNT ≥ 2** (which matches v4
exactly on every shape measured) and pins the one-ANMF shape as a
NEUTRALITY row. If the human prefers the literal bit test, the only change
is the helper's WebP arm and that row flips to a second ruled divergence —
the lane records which it shipped.
