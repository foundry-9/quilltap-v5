- **D-1 (this order's decision) — evidence classes.** Every failure of a
  named beat is put in exactly one class, from the reporter's error block:
  - **BUDGET** — the error text contains `Test timeout of 30000ms exceeded`.
  - **OPEN-WAIT** — an `expect(…).toBeVisible()` at one of the beat's named
    open lines failed with `Timeout 5000ms exceeded` (or `15000ms`).

    not create (an indicator already mounted, a second toast, a line
    already on screen). Each beat names its own FOREIGN-STATE signature.
  - **OTHER** — anything else. **OTHER never gets an edit**: record the
    error block, the trace path and one sentence on what the trace shows.

  There is no trace for a green test (`retain-on-failure`). The JSON report

  that is **BUDGET-MARGIN** evidence and earns `test.slow()` — and nothing
  else. A named beat that passed in under 20 s gets NO edit: record "green
