## The drift, classified (surveyed 2026-08-18)

Kept-alive workspace tabs never remount, so a returned-to tab showed
whatever it had loaded when you left. v4 gives every tab subtree a
visibility signal and, on each hidden→visible transition: (1) a central
invalidator sweeps the TanStack Query prefixes mapped from the tab kind
(`lib/workspace/tab-refetch.ts` — the single source of truth), and
(2) views still fetching outside TanStack re-run their own loads via
`useOnTabActivated` with a new `{ silent }` option so loading flags don't
swap the page (or an in-place detail) for its loading state. Live
surfaces (salon/terminal/document, brahma) and editors with unsaved state
are DELIBERATELY left alone; chat invalidation uses a narrowed
`chats.lists` prefix so per-chat detail/state around a live stream is
never swept. **v5 has ZERO re-activation machinery today** (grep
confirmed: the only related hit is `refetchOnWindowFocus: false`).
