## Survey addendum — the restore side (2026-07-24 @ v4 `e646f58b`, re-verified at re-scoping)

### `json-stream.ts` (163) — the three readers

- **`readJsonFile`** :20 — plain `readFile` + `JSON.parse`. Used for
  `manifest.json` only.
- **`readJsonArrayFile`** :42 — a hand-rolled streaming array scanner (1 MB
  `highWaterMark`), because `JSON.parse` on a full-history `llm-logs.json` blows
  past V8's ~512 MB string cap. It tracks string/escape state and brace/bracket
  depth, and **only supports object/array top-level elements** — a top-level
  scalar throws. **Port its four error strings verbatim**, they are observable:
  `expected '[' at start of <rel>, got <JSON.stringify(c)>` :65,
  `unexpected character after array end in <rel>: …` :72,
  `only object/array elements supported at top level (<rel>), got …` :117,
  `empty file or no array in <rel>` :127, `unexpected end of input in <rel>`
  :130. In Rust this constraint is an implementation freedom, not an obligation —
  but the **error strings on the malformed-archive path are** (they surface in
  the preview/restore response), so reproduce the thrown messages for the inputs
  the differential feeds.
- **`readJsonArrayFileOptional`** :151 — `access` first; missing file → the
  fallback. A **present but malformed** file still throws. (`readJsonFileOptional`
  :139 swallows both — it is unused by the restore path.)

2. `cargo clippy --workspace --all-targets -- -D warnings` — plain **AND**
   `--features quilltap-core/native-transport`
3. `TZ=UTC cargo test --workspace` with this lane's env vars — zero failures.
   Remember `cargo test --workspace` is **fail-fast per binary**; use
   `--no-fail-fast` to see real blast radius.
4. This lane's differentials **by name**, `--nocapture`, zero SKIP, per-case OK
   lines visible — **both** `system_restore_equivalence` (new) and
   `system_backup_equivalence` (landed; it must stay green, and it will move if
   you touch anything under `services/backup/`).
5. Oracles regenerated fresh from `~/source/quilltap-server` at `e646f58b`
   (drift-check FIRST; if v4 moved, STOP and report), and the emitted NDJSON
   grepped for the expected case count before you trust the pass (the standing
   `oracle-regen-silent-stale-pass` rule).
6. `cargo build --release` (the web bin and the host are affected).
7. If tier 2's e2e beat landed: full Playwright over a fresh `ng build` dist +
   rebuilt debug bins. If it did not land, say so explicitly in the lane record
   with the reason — the last lane deferred exactly this beat rather than
   shipping it unverified, and that was the right call.
8. Per-commit rule: follow `.claude/commands/commit.md` (CHANGELOG entry +
   version bumps per §Ownership + the full gate on every commit).

**Disk:** export `CARGO_INCREMENTAL=0` for the whole lane. Parallel worktrees at
default settings will not fit (`target/debug/incremental` alone hit 64 GB in one
past lane); with it off a worktree target stays in the 10–20 GB range. 111 GB was
free at round planning, with two worktrees planned. Check `df -h ~` before
starting and again mid-lane. This lane also stages zips and extracted trees under
the temp dir during tests — clean up after failed runs, and make the tests clean
up after themselves even on failure.
