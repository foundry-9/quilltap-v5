- **The mechanism of class (1), seeded forms.** `app.config.ts:16` sets
  `staleTime: 5_000`. A mount that finds a fresh cache entry never runs its
  `queryFn`, so a draft that is only `set()` inside the `queryFn` stays `''`
  while `isPending()` is already false — the editor mounts EMPTY.
- **The mechanism of class (2), lazy reads.** A TanStack `Query` keeps the
  last `options` an observer gave it. When an observer on key K1 moves to K2
  (its signal changed) the K1 query still holds that observer's `queryFn`
  closure. A later refetch of K1 (an invalidation by prefix, or
  `refetchQueries`) runs that closure, and a `this.x()` inside it now reads
  the K2 value — K1 is filled with K2's data. Any other observer of K1 then
  shows it.
