### Quirks the port must not miss

1. **`tagDetails` is derived, not stored** — present on GET list, GET
   item, and search; **absent** from `getMemoriesByMessage` and
   `countMemoriesByChat`.
2. **`getMemoriesByMessage` returns the trimmed shape** `{id, summary,
   characterId, importance}` — different from every other arm.
3. **Create/read asymmetry**: reads surface server-only fields never
   accepted on create — `embedding`, `witnessedContext`,
   `lastAccessedAt`, `reinforcementCount` (default 1, min 1),
   `lastReinforcedAt`, `relatedMemoryIds`, `reinforcedImportance`
   (`importance + log2(count+1)*0.05`, cap 1.0), `projectId`.
4. **Null vs absent**: the service writes nullables as **explicit
   `null`** (`?? null`), not omitted. `witnessedContext` carries
   semantic weight (`user_present`/`autonomous_room`/`manual`;
   `null` = legacy).
5. **Embedding is polymorphic on read** (Float32Array | number[] |
   Buffer | legacy JSON string → unit-length Float32Array). Whether and
   how `embedding` rides the route's JSON echo is **pinned by the
   oracle, not assumed** — write the list case first, observe v4's
   serialization, port that.
6. **Sorting**: default `createdAt desc`; `importance` sorts on RAW
   importance (not reinforced); paginated path sorts in the DB filter,
   legacy path in-memory; `character-memory-counts` sorts count desc.
7. **The two list code paths** (limit present vs absent) both ship;
   search is ALWAYS applied in-memory even on the paginated path.
8. **Per-user vs instance-wide**: housekeeping-config is per-user
   (`chatSettings`); extraction-limits / recall-config /
   extraction-concurrency are instance-wide. All config writes are
   merge-patch.
9. Housekeeping `details` only on dryRun; `mergeThreshold` min 0.8 on
   the options schema but `autoMergeSimilarThreshold` allows 0–1.
10. **Item PUT does not re-embed** — port the staleness faithfully.
11. **`regenerate-all` is destructive on re-invoke** (wipes in-flight
    jobs first, dedupes on userId).
12. **Create can return `serverError` with no row written**
    (SKIP_EMBEDDING_FAILED).
13. The `memory-creation-dialog.tsx:107` POST to a **path**
    `/chats/{id}/queue-memories` matches no route file — the live wire
    is `?action=queue-memories`; do not port the phantom path.
14. Search determinism: pin the fixture's embedding profile to the
    **builtin TF-IDF** (deterministic; the W4.7e2 ln-ULP seam means idf
    compares at 1e-12 — scores diff at 1e-12, rows structurally).
