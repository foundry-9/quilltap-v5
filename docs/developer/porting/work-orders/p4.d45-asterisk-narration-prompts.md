narration delimiter, asterisk-delimited staff strings teach the model

template's `+` and closed them with `*`). Twelve staff strings across

commit message doesn't count but the diff carries.

(`"*pulls up the file*"` etc. → unquoted prose). The substrings
`system-message-labels.ts` matches on sit inside the wording, so bubble
labels are unaffected (v5's SPA verified already clean:
`system-message-labels.spec.ts:212` asserts without delimiters). Also
adds the 189-line design spec
`docs/developer/features/roleplay-block-narration.md` (mirror it).
