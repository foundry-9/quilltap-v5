logged, sentinel-guarded chain per long step (`run_in_background: true`,
wait for the completion notification; NEVER a `pgrep`/`grep` poll loop;
NEVER `| tail -N` on a gate; capture the FULL log and read the per-binary
`test result:` lines — see CLAUDE.md's standing rule and the
`background-gate-latency-fix` note).

1. **§R.2 probe** — PASS (opening, and again before the regen batch).
2. `cargo fmt --all --check` — clean.
3. `cargo clippy --workspace --all-targets -- -D warnings` — clean in
   BOTH feature sets (default; `--features quilltap-core/native-transport`).

   universal`), run by name and record.
