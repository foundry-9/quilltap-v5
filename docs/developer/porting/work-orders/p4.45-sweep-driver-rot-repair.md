future baseline move can prove them through `harness/tools/recipe_sweep.py
--run` instead of the by-hand runs three consecutive rounds have had to
record. This is the standing maintenance item first flagged at the
`f4955e0e` round, re-confirmed at P4.D56 ("six-family SKIP-masquerade re-run
manually") and at both character-archive unifications. The lane delivers
repaired recipes, a driver that cannot re-grow this rot silently, and a
green `--run` proof for every repaired family. It must NOT change any test
BODY, any fixture, any oracle case's behavior, or any `quilltap-core` /
`quilltap-web` / `quilltap-cli` source — recipe header comments and the
Python driver (+ its README and self-test) only.
