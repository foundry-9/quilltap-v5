## The drift, classified (surveyed FRESH 2026-08-13 at `48396682`)

### The engine (explicitly built for this port)

`v4 lib/smart-typography/engine.ts` (126 lines; ESLint-enforced
stdlib-only "so the v5 copy stays viable"): `EN_DASH`/`EM_DASH`/`ELLIPSIS`,
`SmartTypographyOptions {dashes, ellipsis, reservedChars?}`,
`TypographyInput {before, typed, options}`, `TypographyResult
{deleteBefore: 1|2, insert, rule: 'en-dash'|'em-dash'|'ellipsis'}`,
`smartTypographyStep(input)`. Ladder: `-` after `-` → en dash (delete 1);
`-` after EN_DASH → em dash (delete 1); `.` after `..` → ellipsis
(delete 2). Reserved chars short-circuit. Corpus:
`lib/smart-typography/fixtures/typography-vectors.json` — 15 cases,
`{name, before, typed, expect|null}`, with `defaultOptions`.

### Render-time quotes (Part A)

`v4 lib/markdown/typography.ts` (159 lines): `SMARTYPANTS_OPTIONS =
{quotes:true, ellipses:false, dashes:false, backticks:false}` (`dashes:
false` documented permanent — `run it with --verbose`; `backticks:false`
so `` ` `` pairs don't curl); `isQuoteSensitiveRoleplayConfig`;
`shouldCurlQuotes({displayQuotes, renderingPatterns, dialogueDetection})`.
Suppression rules: (1) **structural** — the plugin runs on mdast, so
code/inlineCode/math/inlineMath and link urls are skipped by node type,
no hand guards; (2) a roleplay `rpBody` pattern containing a straight
quote suppresses curling (`hasRpBodyGroup` mirrors the private
`(?<rpBody>` discriminator); (3) a `dialogueDetection` set naming a
straight quote WITHOUT its curly counterpart suppresses curling.
Renderer hook: `remark-smartypants` inserted **between `remarkBreaks` and
`remarkRehype`**; two cached processors (plain/curled); the dialogue
config is resolved EARLY so suppression reads the SAME config the
dialogue pass uses; the typographer runs before the roleplay HTML layer
(which is why suppression exists). v4 threads `displayQuotes` into its
server pre-render — **v5 has no server pre-render** (locked divergence),
so the whole Part A is client-side.

### Type-time dashes (Part B)

`v4 components/chat/lexical/plugins/SmartTypographyPlugin.tsx` (327
lines) — the behavioral spec for the ProseMirror twin: keydown handled
ABOVE text replacement (first-wins ordering in PM terms); a revert memo
`{nodeKey, endOffset, literal}` — `Backspace` at exactly the end offset
restores the literal; modifier-Backspace never reverts; **any other key
ends the revert window** (keystroke-driven invalidation, not
update-listener); Cmd/Ctrl+Z reverts (tagged update → one undo step);
bails in code contexts, source-mode editors, and IME composition; paste
untouched.

```ts
// code-context.ts — the shared "am I in code?" bail for every typing aid.
// v4's $isInCodeContext (bug 63): one helper so the bail lists cannot drift.
import type { EditorState } from 'prosemirror-state';

export function isInCodeContext(state: EditorState): boolean {
  const { $from } = state.selection;
  if ($from.parent.type === state.schema.nodes['code_block']) return true;
  const codeMark = state.schema.marks['code'];
  if (!codeMark) return false;
  if (state.storedMarks?.some((m) => m.type === codeMark)) return true;
  return $from.marks().some((m) => m.type === codeMark);
}
```
