### Quirks the port must not miss

1. Groups ensure BOTH `Scenarios/` and `Knowledge/`; projects and
   general ensure only `Scenarios/`. The `[scenarioPath]` helpers use
   the RAW `officialMountPointId` (404 when null); the collection
   routes run the full ensure.
2. Envelope drift is per-handler: groups GET = `successResponse`;
   projects GET = bare `NextResponse.json`. The differential pins it.
3. Error-path drift: the scenario-path routes catch ZodError → joined
   400; the union route swallows per-group failures.
4. `isDefault` semantics are three-layered: `rawIsDefault` (file),
   effective `isDefault` (list-time alphabetical resolution),
   `setScenarioDefaultInFolder` (the only writer that demotes
   siblings). There is NO set-default verb — the SPA reuses update.
5. Every mutation returns the FRESH list (one round-trip sync).
6. `parseScenarioDoc` drops empty-body docs with a warning.
7. The general family's unprovisioned race arms (GET nulls, mutations
   throw/400) must survive — the v5 host seeds the general mount
   (P4.4u3), but the arms are still reachable on pre-P4.4u3 instances.
8. `sanitizeFileName` comes from the character-vault port; spaces are
   KEPT (the editor microcopy promises it).

**The scenario bag — re-pinned 2026-07-11 from v4's Zod schemas

- create: `{filename: string (1–100, required), name?: string (1–200),

- update: `{name?: string (1–200), description?: string (≤500),
  isDefault?: boolean, body: string (min 1, required)}` — **no

- rename: `newFilename: string (1–100, required)` — the only field.
- There is NO set-default verb: the SPA sets a default by re-sending
  update with `isDefault: true` (v4's `setDefaultScenario` idiom).

**Response payloads (mock these lane-B-side until unification; bytes
pinned by lane A's differentials):**

- list → `{mountPointId, scenarios, warnings}` (general:
  `mountPointId: string | null`, empty arrays when unprovisioned)
- create → `{mountPointId, path, scenarios, warnings}`
- get → `{scenario}`
- update / delete → `{scenarios, warnings}`
- rename → `{path, scenarios, warnings}`
- union → `{groupScenarios: [{groupId, groupName, mountPointId,
  scenarios, warnings}]}` (groupName order, ICU4X en-US)
- Scenario DTO: `{path, filename, name, description?, isDefault,
  rawIsDefault, body, lastModified, createdAt, updatedAt}`
- `projectFileList` → `{files, count}` (the two-branch legacy-file-
  shaped DTO; store-backed rows add `mountPointId`/`relativePath`)

**Error arms the SPA must surface:** create collision → `A scenario
