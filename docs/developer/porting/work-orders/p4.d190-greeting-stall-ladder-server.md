### C.1 `StreamError` gains a kind (`crates/quilltap-core/src/model/stream.rs` — P4.D189 substrate)

```rust
/// v4 `LLMStreamStalledError` vs everything else. v4 tells the two apart by
/// the error's `name`; v5 has no error-class hierarchy at the stream seam,
/// so the one class that matters to a caller is carried as a kind.
#[derive(Clone, Debug, PartialEq)]
pub enum StreamErrorKind {
    /// A provider failure that reached us as text (every pre-existing site).
    Provider,
    /// The stream watchdog fired (v4 `LLMStreamStalledError`).
    Stalled {
        budget_ms: u64,
        chunks_received: u64,
        provider: Option<String>,
        model_name: Option<String>,
    },
}

#[derive(Clone, Debug)]
pub struct StreamError {
    pub message: String,
    pub kind: StreamErrorKind,
}

impl StreamError {
    pub fn new(message: impl Into<String>) -> Self;   // kind: Provider — every existing call site compiles unchanged
    pub fn stalled(budget_ms: u64, chunks_received: u64, provider: Option<&str>, model_name: Option<&str>) -> Self;
    pub fn is_stalled(&self) -> bool;
    /// v4's `error.name` as the fallback classifier reads it:
    /// `"LLMStreamStalledError"` for `Stalled`, `"Error"` otherwise.
    pub fn v4_name(&self) -> &'static str;
}
```

`StreamError::stalled` renders v4's constructor bytes EXACTLY:
`chunks_received == 0` → `Provider stream never sent a first chunk within
{budget_ms}ms`; otherwise `Provider stream went quiet for {budget_ms}ms
after {chunks_received} chunk(s)`. `Display` stays the bare message. No
other field, no other constructor.

### C.2 The watchdog (`crates/quilltap-core/src/model/stream_watchdog.rs`, NEW — P4.D189 substrate; `pub mod stream_watchdog;` in `model/mod.rs`)

```rust
pub const DEFAULT_FIRST_CHUNK_TIMEOUT_MS: u64 = 240_000;   // v4 DEFAULT_FIRST_CHUNK_TIMEOUT_MS
pub const DEFAULT_IDLE_CHUNK_TIMEOUT_MS: u64 = 120_000;    // v4 DEFAULT_IDLE_CHUNK_TIMEOUT_MS

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct StallBudgets { pub first_chunk_ms: u64, pub idle_ms: u64 }
impl Default for StallBudgets { … }   // the two constants

/// v4's `StallWatchdogOptions.provider/modelName/logContext`, flattened.
#[derive(Clone, Copy, Debug)]
pub struct StallWatchdogContext<'a> {
    pub provider: &'a str,
    pub model_name: &'a str,
    /// v4 `logContext.context`: `"streaming.service"` at every Salon-side
    /// site (v4's one funnel), `"initial-greeting"` at the greeting.
    pub context: &'static str,
    pub user_id: Option<&'a str>,
    pub chat_id: Option<&'a str>,
    pub character_id: Option<&'a str>,
    pub message_id: Option<&'a str>,
}

pub struct WatchedStream<'a> { /* rx, budgets, ctx, chunks_received, started_at, stalled */ }

pub fn watch_stream<'a>(
    rx: tokio::sync::mpsc::Receiver<StreamChunkResult>,
    budgets: StallBudgets,
    ctx: StallWatchdogContext<'a>,
) -> WatchedStream<'a>;

impl WatchedStream<'_> {
    /// The same signature as `Receiver::recv`, so every consumer loop
    /// (`while let Some(item) = rx.recv().await`) is unchanged.
    pub async fn recv(&mut self) -> Option<StreamChunkResult>;
}
```

Semantics (v4 `withStallWatchdog`, per `next()`): the budget for THIS
`recv` is `first_chunk_ms` while `chunks_received == 0`, else `idle_ms` —
per gap, never cumulative. Each `recv` races the inner `rx.recv()` against
`tokio::time::timeout(Duration::from_millis(budget))`. An `Ok(chunk)` from
the source increments `chunks_received` (EVERY yielded chunk counts —
reasoning-only, usage-only, `done` — v4 counts `result.value`s) and is
passed through; an `Err` from the source passes through AS ITSELF (v4: "a
real provider error arrives as itself"); `None` (the source closed) passes
through. On a timeout: ONE `tracing::warn!(target: "quilltap::llm_stream",

`user_id`, `chat_id`, `character_id`, `message_id` (each an `Option`,
rendered only when `Some` — v4's JSON drops `undefined`), `provider`,
`model_name`, `budget_ms`, `chunks_received`, `elapsed_ms` (wall-clock
since `watch_stream`); the inner receiver is DROPPED (v5's "abandoned, not
cancelled" — the host transport pump's next `send` fails and it unwinds);
the call answers `Some(Err(StreamError::stalled(budget, chunks_received,
Some(provider), Some(model_name))))` exactly once, and every later `recv`
answers `None`. Consumer loops treat that `Err` exactly as any mid-stream
`Err` today (`return Some(e)` / `item?` / `break`) — no consumer branches
