### `lib/characters/archive-service.ts` (889 ln) — the port target

The header doc (lines 1–40) is the spec — carry its why-comments. Ordering
is chosen for **crash-safety** (main DB and mount index cannot share a
transaction): 1) write the bundle to an ARCHIVE `files` row encrypted under
the instance passphrase; 2) verify by decrypting and reading back the
ciphertext that will be persisted — a hard gate before anything is deleted;
3) commit the tombstone in one main-DB write; 4) prune (idempotent,
re-runnable). Untouched by design: chats, messages, annotations, group
membership, project rosters, other characters' memories about this one.
