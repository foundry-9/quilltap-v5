## Survey-verified starting points (surveyed 2026-07-19, v4 at `b8b12695`, v5 at `654ce90c`)

**The v4 commit** (`git show b8b12695 --stat`, 20 files):

- **`lib/markdown/math.ts` (NEW, 63 lines)** — the shared math config both v4
  renderers import. Exports `REMARK_MATH_OPTIONS = { singleDollarTextMath:
  false }` (single-dollar math deliberately OFF so currency prose — "He slid
  $50 across the table, then another $20" — is never mangled) and
  `normalizeMathDelimiters(markdown)`: rewrites `\[...\]` →
  `\n$$\n<tex.trim()>\n$$\n` (display math promoted onto its own lines) and
  `\(...\)` → `$$<tex.trim()>$$`, with an early return when the string
  contains neither `\(` nor `\[`. Protected regions via `MATH_SKIP_PATTERN`
  (one capture-group split: fenced ``` and ~~~ blocks, inline code spans,
  existing `$$…$$` runs — whose LaTeX may contain `\[`-lookalikes like
  `\\[3pt]` row spacing). **Unterminated fences and `$$` runs deliberately
  swallow the rest of the string** — during streaming a half-received region
  is left alone rather than half-transformed. Carry every one of these
  why-comments.
- **`__tests__/unit/lib/markdown/math.test.ts` (NEW, 119 lines, 14 cases)** —
  covers both `normalizeMathDelimiters` (9 cases) and the
  `applyRoleplayPatterns` KaTeX skip (5 cases, incl. `katex-display` /
  `katex-error` roots and code-block-skip independence).
- **`lib/services/markdown-postprocess.ts` (NEW, 198 lines)** — v4 moved
  `applyRoleplayPatterns` / `applyDialogueDetection` /
  `applyLineScopedClasses` / `applyWrapBlockClasses` / `escapeHtml` out of the
  service so Jest can import them (the service's unified imports are
  ESM-only). **The ONLY behavioral change in the move is inside
  `applyRoleplayPatterns`:** a `katexDepth` counter — on tag parts, when depth
  > 0, `</`-prefixed tags decrement and non-self-closing tags increment; at
  depth 0 a tag starting `<span class="katex` (matches `.katex`,
  `.katex-display`, `.katex-error` roots) sets depth to 1; text parts inside
  math (depth > 0) are returned untouched exactly like code blocks. The
  soundness note: KaTeX 0.18 markup contains no void or self-closing tags, so
  the generic open/close counter is sound. The other three helpers and
  `escapeHtml` are byte-identical moves.
- **`lib/services/markdown-renderer.service.ts` (-207/+…)** — the plugin
  chain becomes `remarkParse → remarkGfm → remarkMath(REMARK_MATH_OPTIONS) →
  remarkBreaks → remarkRehype → rehypeKatex → rehypeHighlight →
  rehypeStringify` (math parse between gfm and breaks; KaTeX render BEFORE
  highlight). The render body gains **step 2.5**: `normalizeMathDelimiters`
  runs on the trimmed content BEFORE `escapeMarkdownInBrackets` (which would
  otherwise claim `\[...\]` as a roleplay bracket span), plus a
  `logger.debug` when the normalized content contains `$$` (v5 has no logger
  in the renderer — omit it; it is output-neutral).
- **Client/preview/help consumers** (`MessageContent.tsx`,
