### The version surface (the one cross-cutting gap)

- v5's engine `HealthDto` carries `version` (`core-contract.ts:1524`,

  `quilltap-web/src/main.rs:78`, `engine.rs:3044`) — but the HTTP

  a real divergence — surface whichever the human-visible About should
  carry (the SPA `package.json` version is ALSO available at build time
  as a fallback), state the choice in the status header, and keep the §3
  wire field regardless (it is the server's version, useful in its own
  right).
