## The drift, classified (surveyed 2026-08-21, fresh at `12fe3e6f`)

v4's bug-85 client half, in `97d2fcb5`:

1. **The pure evaluator, shared across the wire.**
   `lib/llm/thinking-turn.ts` — `evaluateThinkingTurn({rule, parameters,
   model})`: an explicit profile choice via the provider's declared
   `ThinkingTurnRule` wins (`isUnset` = absent / null / `''` — the empty
   string is how every options-schema enum spells "(model default)");
   absent a choice, `model?.thinksByDefault === true` decides; absent
   that, `false`. Deliberately declarative (a rule serialises through
   `/api/v1/providers`; a plugin closure cannot).
2. **The editor** (`components/settings/connection-profiles/
   ProfileModal.tsx` + `hooks/useProfileForm.ts` + `types.ts`):
   - `runsThinkingTurn` computed from the active provider's
     `thinkingTurnRule`, the form's `parameters`, and the SELECTED
     model's static facts.
   - **Provider change** (new profile only): seeds
     `defaultMultiCharacterPrefill(newProvider)` with a comment that no
     model is chosen yet so only the provider rule can speak.
   - **Model change** (new profile only, `!profile?.id`): re-seeds
     `defaultMultiCharacterPrefill(provider, evaluateThinkingTurn(…))`
     with the newly selected model's facts. A seed, never a clamp — the
     box stays editable.
   - **Stored-null correction** (edit of a row that never chose):
     `useProfileForm` seeds the provider-default immediately (all that
     is knowable there); ProfileModal corrects ONCE when the model list
     lands (`storedPrefillIsUnset && fetchedModelsWithInfo.length > 0`),
     via an effect keyed on the model list landing — "re-running on
     every keystroke would fight the checkbox". Only ever fires for a
     null row, so it can never overwrite a user's choice.
   - **The warning**: when the box is TICKED ∧ the provider default is
     prefill-on ∧ `runsThinkingTurn` — a new paragraph (v4's register,
     transcribe byte-for-byte): "This model reasons before it answers,
     and a turn handed over already opened sits badly with that: some
     providers refuse the request outright, others quietly swallow the
     reasoning altogether. A model that deliberates over whose turn it
     is rarely needs the name put in its mouth — leave this unticked
     unless you have watched yours cope."
   - `types.ts`: `ProviderConfig` gains
     `thinkingTurnRule?: ThinkingTurnRule | null`.
3. **The model listing carries the facts**: v4's
   `components/settings/model-selector.tsx` `ModelInfo` gains
   `supportsThinking?` / `thinksByDefault?`.
4. Help-doc rewrites (`help/connection-profiles.md` — the "Quilltap
   unticks it for you in two cases" section) → the `p4.9i2` bank.

  `false`.
