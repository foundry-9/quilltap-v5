## Shared contract (BINDING — identical in `p4.6be-state-cascade-spa.md`)

### §A — the state dispatch verbs (names + payloads + response bodies)

Nine new CoreRequest variants (serde `rename_all="camelCase"` tags in
comments); response BODIES are v4's route JSON verbatim (envelope per
the existing dispatch convention):

```rust
/// v4 `GET /api/v1/chats/[id]?action=get-state` (participants-union cascade).
ChatStateGet { chat_id: String },                              // "chatStateGet"
/// v4 `PUT /api/v1/chats/[id]?action=set-state`.
ChatStateSet { chat_id: String, state: serde_json::Value },    // "chatStateSet"
/// v4 `DELETE /api/v1/chats/[id]?action=reset-state`.
ChatStateReset { chat_id: String },                            // "chatStateReset"
/// v4 `GET /api/v1/groups/[id]?action=get-state` (OWN state, no cascade).
GroupStateGet { group_id: String },                            // "groupStateGet"
GroupStateSet { group_id: String, state: serde_json::Value },  // "groupStateSet"
GroupStateReset { group_id: String },                          // "groupStateReset"
/// v4 `/api/v1/settings/general-state` GET / PUT / DELETE.
GeneralStateGet {},                                            // "generalStateGet"
GeneralStateSet { state: serde_json::Value },                  // "generalStateSet"
GeneralStateReset {},                                          // "generalStateReset"
```

Response bodies (exact keys):

- `chatStateGet` → `{ "success": true, "state": <merged>, "chatState":
  <obj>, "projectState"?: <obj>, "groupState"?: <obj>,
  "generalState"?: <obj>, "groupTier": <GroupTier>, "projectId"?:
  <string> }` — projectState/groupState/generalState **OMITTED when
  the tier object has zero keys**; projectId omitted when the chat has
  none; `state`/`chatState`/`groupTier` always present.
- `chatStateSet` / `groupStateSet` / `generalStateSet` →
  `{ "success": true, "state": <obj> }`.
- `chatStateReset` / `groupStateReset` / `generalStateReset` →
  `{ "success": true, "previousState": <obj> }`.
- `groupStateGet` / `generalStateGet` → `{ "success": true, "state": <obj> }`.
- `GroupTier` = `{ "status": "none"|"single"|"ambiguous",
  "candidates": [{ "id": string, "name": string }],
  "appliedGroupId"?: string }` (appliedGroupId only when single).
- Set bodies validate v4's `stateBodySchema` (`state` must be a JSON
  object of unknowns); 404s use the existing not-found envelope
