## What v4 changed (audited 2026-07-06)

- New `lib/doc-edit/line-diff.ts` (123 lines): `diffLines(old, new) →
  LineOp[]` — a Myers O(ND) shortest-edit-script diff over line arrays
  (forward v-trace + backtrack, the empty-side fast paths), and
  `changedBlockIndices(baseline, current) → Set<number>` (current-side
  indices of `ins` ops; `del` marks nothing; used by the Phase-4 change
  gutter but shared here as the single source of truth).
- `lib/doc-edit/unified-diff.ts` rewritten: `generateUnifiedDiff` now builds
  on `diffLines` — git-style hunks with `CONTEXT_LINES = 3` of unchanged
  context, maximal changed runs expanded by context and **coalesced when
  expanded ranges touch** (`start <= last.end + 1`), correct
  `@@ -start,count +start,count @@` ranges via `formatRange` (count 0 →
  `start-1,0` pointing before the change, git-style; count 1 → bare start),
  **empty content = zero lines** (no phantom blank line on create/empty),
  and a **whole-file replacement-hunk fallback** past
  `MAX_DIFFABLE_LINES = 10000` combined lines. Exported signatures and the
  surrounding output contract (filename header etc.) unchanged — read the
  full current source; the diff summary above is not the spec.
- (Also in the commit: `DocumentChangeTracker.tsx` gutter — Phase-4 UI, not
  ported, no action.)
