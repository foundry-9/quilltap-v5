## The differential trap (why this order exists at all)

**Every corpus is single-profile, so the current differentials PASS with
the hard-coded config** — that is exactly how #27 slipped in (the #16/#22
corpus-invisible-call-site class). A fix with no new corpus case is
unverified by definition. The equivalence requirement for this lane is
therefore: **at least one case per fixed site where the SELECTED profile
differs from the responding character's profile**, pinned via the
`llm_logs` row's provider/model columns (and the `background_jobs` /
summary rows the families already diff).
