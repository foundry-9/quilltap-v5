### v4 — the feature anatomy (all in commit `7df7de8e`)

- **`lib/schemas/settings.types.ts` (+32):** `TabooSettingsSchema =
  z.object({ phrases: z.array(z.string().trim().min(1).max(200))
  .max(500).default([]) })`. Same instance-settings class as
  `dataRetention` — the doc comment names the accessors and the
  renderer. Mind the Zod `.trim()` INSIDE the element validator: a
  201-char phrase that trims to ≤200 is valid; validation runs on the
  trimmed value ([[p4.6an-dangerous-content-parse-gap]] class — be
  Zod-faithful, not approximately faithful).
- **`lib/instance-settings/index.ts` (+86):** `KEY_TABOO = 'taboo'`,
  `DEFAULT_TABOO_SETTINGS = { phrases: [] }`,
  `normalizeTabooPhrases(readonly string[]): string[]` (trim → drop
  empty → dedupe by `phrase.toLowerCase()` fingerprint keeping FIRST,
  order preserved), `getTabooSettings()` (default when never
  written), `setTabooSettings()` (stores the NORMALIZED list and
  returns what it stored, so PUT echoes storage, never the raw
  submission). The taboo key is **portable by default** — v4's
  denylist mechanism (`NON_PORTABLE_INSTANCE_SETTING_KEYS`) is
  unchanged, and `portable-settings.test.ts` (+2) just adds the
  taboo row to the portable-side fixture. v5's mirror is
  `db/instance_settings.rs:402` (`NON_PORTABLE_INSTANCE_SETTING_KEYS`
  + `list_portable_instance_settings`) — **no change needed there**;
  verify, don't edit.
- **`lib/chat/context/system-prompt-builder.ts` (+71):**
  `TABOO_SECTION_PREAMBLE` — a multi-line constant whose every clause
  is load-bearing (the in-code comment names the three failure modes:
  pink-elephant salience, prohibition-without-alternative,
  literal-string dodging; CARRY that comment, per the small-units
  rule). `renderTabooSection(phrases)` returns `null` on
  empty/undefined; re-trims defensively; emits `- "phrase"` bullet
  lines joined under the preamble. `buildSystemPrompt` gains optional
  `tabooPhrases?: string[]`; the section is pushed with the universal
  material (after the math note, before the per-turn tool

  contain `{{...}}` and must reach the model literally).
