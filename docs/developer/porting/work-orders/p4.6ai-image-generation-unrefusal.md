### Quirks the port must not miss

1. The generate route accepts extras (`size?/quality?/style?/
   aspectRatio?/negativePrompt?`) that the `imageProfileGenerate`
   variant does NOT carry (only the Shared-contract four). The SPA
   sends only the four — the narrowing is a KNOWN, recorded divergence
   at the dispatch layer; report if the differential trips on it, don't
   silently widen the variant.
2. The response `metadata` block (`{originalPrompt, provider, model,
   count}`) is unread by the SPA but diffed by the oracle — EMIT it.
3. `notFound('Image profile')` on a missing profile; `!result.success`
   → 400 with `result.error || 'Image generation failed'`.
4. Success is v4 status **201**.
