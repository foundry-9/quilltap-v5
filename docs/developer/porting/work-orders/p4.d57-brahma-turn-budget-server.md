## ⚠ The PUT tri-state (the taboo `double_option` lesson)

v4's PUT merges `{...current, ...body}` then `safeParse`s. For the single
`maxAgentTurns` field this means three distinct inputs:

- **absent** (`{}`) → keeps `current.maxAgentTurns` → parses → 200;
- **explicit `null`** (`{"maxAgentTurns": null}`) → `z.number()` rejects null →
  **400** (validationError);
- **a number** → validate against `int().min(5).max(200)` → 200 or 400.

The Taboo round's §3 review found a real bug where a dispatch leg collapsed
"absent" and "null", silently keeping the value where v4 400s. **Model the
update payload so absent ≠ null ≠ value** — the `#[serde(default, with =
"double_option")]` `Option<Option<i64>>` pattern the taboo/dangerous-content
work already uses (see the `double_option` note in `api/types.rs` and
`p4.6an-dangerous-content-parse-gap`). Pin all three arms in a serde unit test
next to the taboo `taboo_update_phrases_tristate_survives_serde` test, and cover
them in the differential. The web edge's hand-built variant is where the taboo
bug hid — make the differential drive BOTH the dispatch verb and the REST edge.

## Shared contract (BINDING — identical in P4.D59)

The Brahma Console settings surface the SPA card (P4.D59) consumes. Verbatim,
name-level:

**Dispatch (CoreRequest / Response):**

- **Get** — `Request` variant `BrahmaConsoleSettings`, wire `type:
  "brahmaConsoleSettings"`, no fields. Response variant `BrahmaConsole(Value)`,
  wire `type: "brahmaConsole"`, body `{ "maxAgentTurns": <int> }`.
- **Set** — `Request` variant `BrahmaConsoleSettingsUpdate`, wire `type:
  "brahmaConsoleSettingsUpdate"`, field `maxAgentTurns` (tri-state: absent =
  keep current, null → 400, number → validate). Response variant
  `BrahmaConsole(Value)` carrying the STORED `{ "maxAgentTurns": <int> }`.

**REST edge (v4-URL parity):** `GET /api/v1/settings/brahma-console` →
`{ "maxAgentTurns": <int> }`; `PUT /api/v1/settings/brahma-console` with body
`{ "maxAgentTurns": <int> }` → merge over current, validate, persist, return
`{ "maxAgentTurns": <int> }`; **400** on out-of-range or null.

**Semantics:** `maxAgentTurns` is an integer in **[5, 200]**, default **50**.
