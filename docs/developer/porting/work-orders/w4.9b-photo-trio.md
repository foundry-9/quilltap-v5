Jest real-DB oracle driving v4's REAL handlers over a two-DB fixture
(two characters — one transparent peer, one opaque; vaults with baked

link-id, attach by fileId→sha, attach cross-vault refusal, attach
width/height join. Diff: outputs + `format*` strings byte-for-byte + the
five mount-index tables + `files` (shared id-map remap; minted
timestamps in the content-addressed `.md` per
`[[tool-handler-differential-minted-remap]]`). Regenerate
`tool_dispatch_equivalence` (+1 row using `list_images`).

## Watch-outs

- The dedup guard is per-mount + photos/-only — a sha existing elsewhere in
  the vault must NOT block a keep; bank it.
- The keep timestamp appears in the filename AND the attribution footer AND
  frontmatter — one mint, three sinks; the remap must treat them as one
  token.
- The chunker must be the SAME deterministic database-backed chunk pass the
  groups/projects differentials pinned — if v4 chunks the markdown through
  a different path here, verify determinism before diffing chunk rows (else
  pin/exclude them as those differentials did).
- `linkedByRole` back-compat: rows without it parse as `'character'`.
