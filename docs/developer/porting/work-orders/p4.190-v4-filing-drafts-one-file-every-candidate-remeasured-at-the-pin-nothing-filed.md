  - **Trap (memory note `v4-path-quoting-traps`):** v4 paths contain `[id]`
    and `[...path]`. ALWAYS single-quote the `<rev>:<path>` argument.
  - **Trap (memory note `grep-wrapper-skips-binary-files`):** if `ggrep`
    prints nothing for a file that should match, pipe to `/usr/bin/grep -an`
    instead before concluding "absent".
  - Needle found → note the exact line numbers and copy at most three lines
    of text for the draft.
  - Needle not found in that file → search the tree at the pin:
    `git -C ~/source/quilltap-server grep -n '<needle>' 624d0d25c -- lib app components help`.
    Found elsewhere → use that site and record "moved from `<old>`". Found
    nowhere → the status is CANNOT REPRODUCE BY READING (G5) unless
    `git -C ~/source/quilltap-server log --oneline -S'<needle>' 624d0d25c -- <dir>`
    shows the commit that removed it — then FIXED UPSTREAM with that sha.

  - Log empty → "unchanged since the pin".
  - Log non-empty → read `git -C ~/source/quilltap-server diff 624d0d25c <MAIN-sha> -- '<path>'`.
