## Mandate

`lib/api/middleware/actions.ts` does — **`?action=` (present but empty)
takes the NO-ACTION leg**, an **unknown action answers v4's exact
`{error: "Unknown action: <x>", availableActions: [...]}` 400**, a missing
action with no default answers v4's `{error: "Action parameter required",
availableActions: [...]}` 400 — and make every v5 query read agree with
v4 on which of a DUPLICATED key's values wins (`searchParams.get` reads
the FIRST; v4's `getQueryParamsWithoutAction` / `forEach` reads the LAST;

## Survey-verified starting points (2026-09-02)

1. **v4's ONE action reader.** `lib/api/middleware/actions.ts:59`
   `getActionParam(request) = request.nextUrl.searchParams.get('action')`
   — `URLSearchParams.get` returns `''` for `?action=` and the **FIRST**
   value for `?action=a&action=b`. `withActionDispatch(actions,
   defaultHandler)` (`:85-135`): `if (action)` — so `''` is FALSY and
   falls to the no-action leg: `defaultHandler` if given, else a 400
   `{error: 'Action parameter required', availableActions:
   Object.keys(actions)}` (+ a `warn('No action param and no default
   handler', {method, path, availableActions})`). A truthy action not in
   the map answers 400 `{error: \`Unknown action: ${action}\`,
   availableActions: Object.keys(actions)}` (+ `warn('Unknown action
   requested', {action, availableActions, method, path})`). **55 route
   files** consume this middleware (`grep -rl "middleware/actions"
   app/api`). Three routes read `action` by hand instead —
   `v1/system/unlock/route.ts:76`, `v1/scenarios/[scenarioPath]/route.ts:163`,
   `v1/chats/[id]/files/route.ts:43` — each with its own truthiness
   shape; read each. `availableActions` is `Object.keys(actions)` —
   **insertion order of the route file's handler map**, a per-route
   constant the oracle records for you.
2. **v5's action readers — 31 sites in 13 files** (`grep -rn
   'get("action")' crates/quilltap-web/src`): `backup_routes.rs:120`,
   `brahma_routes.rs:103`, `characters_routes.rs:314/365/418/519`,
   `chats_routes.rs:38`, `custom_tools_routes.rs:58/131/153`,
   `embedding_profiles_routes.rs:87/175`, `files_routes.rs:213/806/1006/
   1029`, `profile_routes.rs:72`, `system_data_routes.rs:209/347/513/523/
   555/700` (`:361` is a BODY key, not the query — leave it),
   `text_replacements_routes.rs:125/291`, `wardrobe_routes.rs:119/139/144/
   285/362`. Every one reads through `Query<HashMap<String, String>>`
   (43 extractors in the crate), which under serde_urlencoded keeps the
   **LAST** duplicate and yields `Some("")` for `?action=` — so today
   `?action=` reaches the `Some(other)` / `_` arms (e.g.
   `characters_routes.rs:316`'s v5-invented sentence `This route serves
   ?action=archive and ?action=rehydrate only; …`) where v4 takes the
   no-action leg. ⚠ `photos_routes.rs` already got this right for `tag`
   (`Vec<(String, String)>` extractor, header lines 12-16) — the pattern
   to generalize.
