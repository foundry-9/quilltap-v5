## Shared contract (BINDING — identical text in P4.D74 and P4.D75)

The three settings keys, name-for-name on the wire (GET echo and PUT):

- `composerEmoji`: boolean, default `true`.
- `composerUnicode`: boolean, default `true`.
- `smartTypographySettings`: object `{ "displayQuotes": boolean (default
  false), "dashes": boolean (default true), "ellipsis": boolean (default
  true) }`, keys serialized in that order. PUT accepts a partial bag
  (missing keys default per-key); a non-boolean value or a null bag is a
  400.
- The SPA reads them from the existing chat-settings GET and saves via the
  existing PUT with single-key payloads (`{"composerEmoji": false}`,
  `{"smartTypographySettings": {...}}`), exactly like `composerSpellcheck`
  today.
- **Toggle semantics** (behavioral, for the SPA lanes): the two composer
  booleans gate the automatic trigger ONLY — toolbar picker buttons are
  never gated. `smartTypographySettings.displayQuotes` is render-time
  display-only (stored bytes never change); `dashes`/`ellipsis` are
  type-time content edits.
- **Version bumps:** this lane bumps `quilltap-core` + `quilltap-harness`;
  P4.D74/P4.D75 bump the SPA.
