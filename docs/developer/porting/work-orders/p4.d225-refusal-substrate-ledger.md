### A. `refusal.ts` (p1, 220 lines) — the classifier, verbatim rules

  inferred`. `RefusalVerdict { refused; evidence?; detail? (≤ 200) }`.
  `RefusalInput { error?; finishReason?; emptyBody?; contentWasFlagged? }`.
  `classifyRefusal(input)` (:196-215); `isModerationRefusal(error)` =
  `classifyRefusal({ error }).refused`.

  violation','content_filter','safety','1301']` (compared LOWER-CASED).
  `REFUSAL_MESSAGE_PATTERNS = ['content moderation','content_policy',

  'MODERATION_REJECTED' || record.name === 'ModerationRejectionError'`) →
  `typed-error`, detail `truncate(providerReason ? \`${message}

  (`providerReason` only if a string); (2) `error != null` AND a collected
  code lower-cased ∈ the set → `provider-code`, detail `truncate(\`code
