4. Files last, sequentially (:146-158): `if (file.storageKey)
   fileStorageManager.deleteFile(file)` then `repos.files.delete(file.id)`,

5. `clearFormat3Entities()` (:164).

**`deleteAllUserData` (:215-290)** counts eleven lists BEFORE deleting (:221-233

**`previewDeleteAllUserData` (:299-349)** repeats the same counting with no
