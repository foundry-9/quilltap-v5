## Survey-verified starting points (2026-08-31, from the shipped hunks — ledger §5.3)

1. **Bug 108 — `lib/tools/handlers/doc-edit/text-handlers.ts` (+77).**
   Context to carry: the tool dispatcher DELIBERATELY passes raw input to
   a handler when the Zod parse fails (that is what lets a `qtap://` URI
   stand in for scope/mount/path) — so the guards live in the handlers,
   not the dispatcher. `handleStrReplace` (:346–:381):
   `typeof input.find !== 'string' || input.find.length === 0` → the
   fixed sentence ``The `find` argument was ${what}. doc_str_replace
   needs `find` (the exact existing text) and `replace` (what to put in
   its place); nothing in ${input.path} was changed. This is a problem
   with the call, not with the file — re-issue it with both arguments.``
   with `what` = `'empty'` vs `'missing'`; **`replace` is guarded by
   `typeof`, not truthiness** (:364) — `''` is a legitimate deletion, and
   without the typeof an omitted `replace` spliced the literal string
   `"undefined"` into the document (carry the why-comment).
   `handleInsertText` gains the `position`/`content` guards (:228–:269
   region — note the existing `typeof input.content` arms and match v4's
   final shape from the post-commit file). →
   `quilltap-core/src/tools/doc_edit/text.rs` +
   `tools/doc_edit/shared.rs`.
2. **Bug 109 — NEW `lib/doc-edit/typographic-folding.ts` (+121).**
   `TYPOGRAPHIC_FOLDINGS` (:52 — the quote family, the dash family, the
   ellipsis, the non-breaking spaces, onto ASCII),
   `foldTypographicChar` (:96), `foldTypography` (:107),
   `hasTypographicVariants` (:116). → a NEW v5 module
   (`quilltap-core/src/doc_edit/typographic_folding.rs`), transcribed
   byte-for-byte (the byte-exact static-data transcription rule — if the
   table is big enough to rot, ship a generator; at ~40 rows a
   transcription with a shape-assert against v4's table via the oracle is
   acceptable).
3. **`lib/doc-edit/diacritics.ts` (+183/−52) — REBUILT** so the searched
   string and its position map come from ONE per-character function: **a
   length-changing fold must map back correctly** (the ellipsis folds one
