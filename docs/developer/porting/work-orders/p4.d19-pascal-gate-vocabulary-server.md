### v4 — the gate (`6864bf0e`)

**New `lib/pascal/metadata-match.ts` (105 lines).** The fail-soft comparison
table, lifted verbatim out of `custom-tools.ts`'s `matchesMetadataComparator`
and given two hooks:

```ts
export interface MetadataMatchHooks {
  resolveOperand: (key: (typeof COMPARATOR_KEYS)[number]) => Primitive;
  onDecline?: (reason: string) => void;
}
export function metadataComparatorHolds(
  comparator: MetadataComparator, key: string,
  metadata: Record<string, unknown>, hooks: MetadataMatchHooks
): boolean
```

Semantics are **unchanged from what v5 already has** in
`custom_tools.rs:803` (`matches_metadata_comparator`) — absent key declines,
non-primitive subject declines with the `null`/`an array`/`an object` wording,
ordering requires numbers on both sides, `eq`/`neq` are `!==`/`===` on the raw
value, containment requires strings on both sides and `ncontains` inverts.
**The decline REASON strings are load-bearing** (v4 logs them; v5's port
already carries them) — keep them byte-identical. `isPrimitive` moves here too.

**New `lib/pascal/tool-gate.ts` (82 lines).**

```ts
export interface ToolGateVerdict {
  available: boolean;
  withheldBy?: 'availableWhen' | 'withheldWhen';
}
export function hasToolGate(d): boolean   // either clause present
export function evaluateToolGate(d, metadata: Record<string, unknown> | null | undefined): ToolGateVerdict
```

- `sheet = metadata ?? {}`.
- `availableWhen` present and NOT satisfied → `{available:false, withheldBy:'availableWhen'}`.
- else `withheldWhen` present and satisfied → `{available:false, withheldBy:'withheldWhen'}`.
- else `{available:true}` (and **`withheldBy` absent, not null** — it is an
  optional key; the v5 serialization must omit it, not emit `null`).
- `gateHolds` ANDs every key; the operand resolver is the identity (literals
  by construction).
- **Fail-soft ⇒ fail-CLOSED for `availableWhen`:** an empty sheet fails every
  `availableWhen` and satisfies no `withheldWhen`. That asymmetry is the whole
  reason both keys exist; do not "simplify" one into a negation of the other.

**`lib/pascal/custom-tool.types.ts`** gains (see the diff for exact Zod):
- `GateComparatorSchema` — a `strictObject` with the same eight keys, but
  **every operand a literal**: `gt/gte/lt/lte: z.number().finite()`,
  `eq/neq: z.union([number().finite(), string(), boolean()])`,
  `contains/ncontains: z.string().min(1, 'the substring to look for must not be empty')`,
  `.refine(hasComparator, AT_LEAST_ONE_WIDE)`. **No `$param`, no `$state`** —
  those are load-time rejections.
- `ToolGateSchema` — `strictObject({ metadata: z.record(MetadataKeySchema,

  add a second one.

  `declares both availableWhen and withheldWhen — a definition gates one way
  or the other. Fold the second test into the first, remembering that a key
  the character lacks never matches.`
- `KNOWN_TOP_LEVEL_KEYS` gains both names in the same position.

## Shared contract (binding — identical in all four sibling orders)

**§1 — `references` on a chat custom-tools listing.** Emitted by **P4.d19**,
consumed by **P4.d21**. Verbatim:

```jsonc
// GET /api/v1/chats/{id}/custom-tools → { tools: [ { ... } ] }
// Each listing gains ONE new key, positioned after `parameters`
// and before `defaultVisibility`:
"references": {
  "value":    false,        // boolean — some rendered string quotes {{value}}
  "roll":     false,        // boolean — {{roll}}
  "dice":     false,        // boolean — {{dice}}
  "llm":      false,        // boolean — {{llm}}
  "params":   [],           // string[] — DECLARED params quoted as {{params.x}}, sorted (en-US collation)
  "metadata": [],           // string[] — keys from when.metadata, BOTH gate clauses, and {{metadata.x}}, sorted
  "state":    []            // string[] — paths from $state refs and {{state.x}}, sorted
}
```

All seven keys are **always present** (never absent, never null). A tool that
quotes nothing yields four `false`s and three `[]`s — the consumer renders no
panel in that case (`isEmptyVocabulary`).

"gate": { "available": true }                                  // available
"gate": { "available": false, "withheldBy": "availableWhen" }  // or "withheldWhen"
