## The drift, classified (surveyed 2026-07-30)

1. **`77ff4e2e` (the SPA half)** — v4's `components/terminal/Terminal.tsx`
   at xterm 6:
   - **The selection color actually applies now**: xterm 6 renamed the
     `selection` theme key to `selectionBackground`; v4's untyped return
     let the dead key survive silently. v5 is AHEAD here —
     `apps/web/src/app/terminal/terminal.ts:186` already reads
     `--qt-terminal-selection` into `selectionBackground` (verified at
     planning). Record; no change.
   - **Six NEW optional theme knobs**, read with an `undefined` fallback so
     xterm derives them from bg/fg when a theme doesn't set them
     (`getColor`'s `#000000` fallback would paint them hard black):
     `cursorAccent` ← `--qt-terminal-cursor-accent`,
     `selectionForeground` ← `--qt-terminal-selection-fg`,
     `selectionInactiveBackground` ← `--qt-terminal-selection-inactive`,
     `scrollbarSliderBackground` ← `--qt-terminal-scrollbar`,
     `scrollbarSliderHoverBackground` ← `--qt-terminal-scrollbar-hover`,
     `scrollbarSliderActiveBackground` ← `--qt-terminal-scrollbar-active`.
     v5's `readTerminalTheme()` (terminal.ts ~:174-200) has NO optional
     tier and its `get()` falls back to `'#000000'` — porting the knobs
     without the undefined-fallback distinction would repaint every theme's
     scrollbar black. Port the two-tier read.
   - **Exited sessions become non-typeable**: v4's old code poked
     `term._input` (not a real xterm field in ANY version — the guard
     always short-circuited, so the fix is NEW live behavior, not a
     restoration); it now disables `term.textarea`. v5 writes the
     session-ended line (`terminal.ts:90-96`) but never disables input —
     mirror via the xterm `textarea` handle. (v5 already touches the same
     handle by DOM query in `terminal-embed.ts:189` for focus; prefer the
     instance property in the component that owns the term.)
   - **The canvas addon is GONE in xterm 6** (the addon peers on ^5). v5
     never loaded it (verified at planning) — record; no change.
   - The `_variables.css` comment block documenting the six optional knobs
     (deliberately left undefined) — mirror into v5's terminal variable
     block so theme authors find the contract.
